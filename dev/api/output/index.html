Output

Aeolus.Output (ONE-c, #452) is the one output writer of the model. It replaces three writers: the simulation run type's fields_<step>.nc, the urban case's NetCDF file and the SBL run type's series.csv.

Every component publishes an output catalogue, a list of OutputVariables. Each variable has a name, units, dimensions (:xyz, :xy, :z, :k — a spectrum over the shell wavenumbers —, :scalar) and a getter. The model's catalogue is the core's variables plus every enabled component's (domain_catalogue), and [output] variables selects from it. Selecting a variable that no enabled component publishes is a configuration error.

OutputWriter writes the selection into one NetCDF-4 file (output/output.nc by default) as two record streams:

  • the records (unlimited dimension time): 3-D fields, surface maps, profiles, and per-record scalars, written every [output] cadence;
  • the time series (unlimited dimension time_series): scalars such as the domain means and the budgets, written every series_cadence.

With averaging = "mean" every value is the time mean over its interval. The writer accumulates it every step, weighted by the step length, and the variable carries cell_methods. A checkpoint stores the open intervals (output_means), so a run resumed from it writes the same means as the uninterrupted run.

[output]
variables = ["u", "v", "w", "theta", "theta_profile", "theta_mean", "budget_energy"]
cadence = 600.0          # s, the records
series_cadence = 60.0    # s, the time series (0: every step)
averaging = "instant"    # or "mean"

The default set is u, v, w, theta and the time series of the domain means of u, v, w and θ. A budget_* variable switches on the budget it writes (Budgets). Its terms are written as the group budget_<q>__<stage>__<name> (cumulative since the start), with __storage and __closure.

Aeolus.Output — Module
Aeolus.Output

The one output writer of the model (ONE-c, #452; the design is docs/src/design/single_model.md, "Output"). It replaces the three writers the run types had (the simulation run type's fields_<step>.nc, the urban case's NetCDF and the SBL run type's series.csv).

Every component publishes an output catalogue: a list of OutputVariables (name, units, long name, dimensions and how the value is computed). The configuration selects variables from the catalogues of the enabled components ([output] variables); the writer (OutputWriter) writes them into one NetCDF-4 file (through Aeolus.NCIO) as two record streams:

  • the records (unlimited dimension time): 3-D fields (:xyz), surface maps (:xy), vertical profiles (:z) and per-record scalars, every [output] cadence;
  • the time series (unlimited dimension time_series): scalars (:scalar, e.g. the domain means), every series_cadence.

With averaging = :mean every written value is the time mean over the interval since the last record of its stream (the writer accumulates every step, weighted by the step length; the variables carry cell_methods = "time: mean"); with :instant it is the value at the record's time.

Aeolus.Output.OUTPUT_DIMS — Constant
OUTPUT_DIMS

The dimensions an output variable can have: :xyz (a 3-D field, per record), :xy (a surface map, per record), :z (a vertical profile, per record), :k (a spectrum over the writer's wavenumbers k, per record) and :scalar (one number: a time series, or a per-record value).

Aeolus.Output.OutputVariable — Type
OutputVariable(name, units, long_name, dims, getter; eltype = Float32 (Float64 for :scalar),
               group = false)

One variable of an output catalogue. dims is one of OUTPUT_DIMS; getter(ctx) returns its value for the writer's context ctx (a model domain, an urban case, …): an interior-sized (Nx, Ny, Nz) array for :xyz, (Nx, Ny) for :xy, a length-Nz vector for :z, a vector of the length of the writer's wavenumbers k for :k, a number for :scalar. With group = true (a :scalar variable) getter returns a Dict{String,Float64}: a group of scalars, written as <name>__<key> and defined as they appear (the budget terms, which appear as the run books them).

Aeolus.Output.OutputWriter — Type
OutputWriter(path; x, y, z, k = nothing, records = [], series = [], statics = [], ctx = nothing,
             time_units = "s", attributes = Dict(), averaging = :instant, resume_at = nothing,
             resume_time = nothing)

The writer of one run's output file path (NetCDF-4, Aeolus.NCIO): coordinates x, y, z (cell centres, m) and, for spectra, k (rad m⁻¹), the record variables records (any of OUTPUT_DIMS; unlimited dimension time), the time-series variables series (:scalar; unlimited dimension time_series), and statics, written once from ctx (:xy or :xyz maps without a time dimension: the static geometry). time_units is the units of the two time coordinates (CF: "seconds since …").

averaging = :mean writes the mean over each record's interval (call accumulate_output! after every step); :instant the value at the record. resume_at = n reopens an existing file and continues its records at record n (a run resumed from a checkpoint, #269); resume_time = t reopens it and continues both streams after their last sample at or before t (the samples after it, written by an interrupted session, are overwritten). With no variable at all no file is written (output_path is nothing).

Aeolus.Output.accumulate_output! — Method
accumulate_output!(w, ctx, dt) -> w

With averaging = :mean, add the current values of every variable times the step length dt to the record and time-series means (call it after every step). A no-op with :instant.

Aeolus.Output.catalogue_names — Method

The names of a catalogue, in order.

Aeolus.Output.cell_centres — Method
cell_centres(mesh) -> (x, y, z)

The cell-centre coordinates of mesh (m from its origin): uniform in x and y, zc of a stretched grid in z.

Aeolus.Output.check_catalogue — Method
check_catalogue(vars) -> vars

Throw an ArgumentError if two variables of the catalogue vars share a name.

Aeolus.Output.close_output! — Method

Close the writer's file (if it has one).

Aeolus.Output.output_means — Method
output_means(w) -> state
restore_output_means!(w, state) -> w

The open intervals of a :mean writer: per stream the accumulated $Σ value·dt$ of every variable and $Σ dt$ since its last record. A checkpoint taken between two records stores them, so that a run resumed from it writes the same means as the uninterrupted run (the first record after the checkpoint averages over the whole interval, not only the part after the restart). state is self-contained (deep copies).

Aeolus.Output.output_path — Method

The path of the writer's file, or nothing when it writes none.

Aeolus.Output.select_variables — Method
select_variables(catalogue, names) -> Vector{OutputVariable}

The variables of catalogue named in names, in the order of names; an ArgumentError names any that the catalogue does not have.

Aeolus.Output.write_record! — Method
write_record!(w, ctx, t; at = nothing) -> w

Write one record of the record variables at time t (s): their values now (:instant) or their means since the last record (:mean; nothing is written for an empty interval). at writes it as record at (a resumed run rewrites the records after its checkpoint).

Aeolus.Output.write_series! — Method
write_series!(w, ctx, t) -> w

Append one sample of the time-series variables at time t (s), like write_record!.
