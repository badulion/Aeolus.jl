Operators

The Aeolus.Operators module is a thin dispatch façade. Each function here forwards to a location-and-mesh-specialized kernel in the FiniteVolume submodule (see Multiple dispatch).

First derivatives

Aeolus.Operators.∂x — Function
∂x(out, f); ∂y(out, f); ∂z(out, f)

Partial derivative of f into out. The combination of input and output Locations selects the discrete stencil:

  • (CellCenter, CellCenter) → 2nd-order centered, cell → cell.
  • (FaceX, CellCenter) → 2-point gradient, cell → face (pressure-gradient use).
  • (CellCenter, FaceX) → 2-point difference, face → cell (divergence contribution).

Halos of f must be filled before calling. Returns out.

Aeolus.Operators.∂y — Function
∂x(out, f); ∂y(out, f); ∂z(out, f)

Partial derivative of f into out. The combination of input and output Locations selects the discrete stencil:

  • (CellCenter, CellCenter) → 2nd-order centered, cell → cell.
  • (FaceX, CellCenter) → 2-point gradient, cell → face (pressure-gradient use).
  • (CellCenter, FaceX) → 2-point difference, face → cell (divergence contribution).

Halos of f must be filled before calling. Returns out.

Aeolus.Operators.∂z — Function
∂x(out, f); ∂y(out, f); ∂z(out, f)

Partial derivative of f into out. The combination of input and output Locations selects the discrete stencil:

  • (CellCenter, CellCenter) → 2nd-order centered, cell → cell.

Second-order operators

Aeolus.Operators.laplacian — Function
laplacian(out, f)

Apply the 7-point 2nd-order centered discrete Laplacian to f, writing ∇²f into out. out must live at the same Location as f. Halos of f must be filled.

Aeolus.Operators.divergence — Function
divergence(out, u, v, w)

Discrete divergence ∇·u written to out at CellCenter.

Two methods:

  • u@FaceX, v@FaceY, w@FaceZ → staggered Arakawa-C divergence (the physically correct one; used in the pressure projection).
  • u@CellCenter, v@CellCenter, w@CellCenter → collocated 2nd-order centered divergence (diagnostic only).

Halos of u, v, w must be filled.

Advection

Aeolus.Operators.advect_centered! — Function
advect_centered!(tend, u, v, w, ϕ)

Add -(u·∇)ϕ (or equivalently -∂(uⱼϕ)/∂xⱼ for ∇·u = 0) to tend using 2nd-order centered stencils. Two methods:

  • u,v,w @ Face…, ϕ @ CellCenter — staggered flux form (used for θ in the Boussinesq core).
  • u,v,w,ϕ @ CellCenter — collocated advection-form (diagnostic / passive-tracer runs).

Non-monotone: overshoots near sharp gradients. Use advect_upwind! for stronger monotonicity at the cost of diffusion.

Aeolus.Operators.advect_upwind! — Function
advect_upwind!(tend, u, v, w, ϕ)

Add -(u·∇)ϕ to tend using 1st-order upwind differencing. Monotone but highly diffusive; a placeholder for the WENO-5 kernel planned in Phase 2. Collocated (CellCenter) only.

Aeolus.Operators.momentum_advect! — Function
momentum_advect!(tu, tv, tw, u, v, w)

Add -∂(uⱼuᵢ)/∂xⱼ (momentum flux divergence) to the three face-centered tendencies (tu, tv, tw). 2nd-order centered flux form on Arakawa-C. Halos of u, v, w must be filled.

Physics forcings

Aeolus.Operators.add_buoyancy! — Function
add_buoyancy!(tw, θ, θ₀, g_accel)
add_buoyancy!(tw, θ, qv, θ₀, g_accel)

Add the Boussinesq buoyancy tendency to the w-momentum tendency tw.

  • 4-argument form: dry buoyancy g·(θ - θ₀)/θ₀.
  • 5-argument form: moist buoyancy g·(θᵥ - θ₀)/θ₀ with virtual potential temperature θᵥ = θ (1 + 0.61 qv) (Phase 11).

θ (and qv) are interpolated in z to the z-face location of w.

Aeolus.Operators.add_coriolis! — Function
add_coriolis!(tu, tv, u, v, f)

f-plane Coriolis: add +f v to tu (with v interpolated to u's face) and -f u to tv (with u interpolated to v's face). 4-point horizontal averaging preserves symmetry.

Subgrid-scale closure

Aeolus.Operators.compute_smagorinsky_νt! — Function
compute_smagorinsky_νt!(νt, u, v, w, C_s)

Compute Smagorinsky-Lilly eddy viscosity at cell centers:

\[\nu_t = (C_s \Delta)^2 \, |S|, \quad |S| = \sqrt{2\, S_{ij} S_{ij}}\]

with Δ = (dx·dy·dz)^{1/3} and strain-rate tensor Sᵢⱼ = ½(∂uᵢ/∂xⱼ + ∂uⱼ/∂xᵢ). Diagonal components live natively at cell centers on a C-grid; off-diagonals are formed at edges and averaged to the center. Halos of u, v, w must be filled.

Aeolus.Operators.compute_dynamic_smagorinsky_νt! — Function
compute_dynamic_smagorinsky_νt!(νt, u, v, w;
                                workspace = DynamicSmagorinskyWorkspace(mesh(u)),
                                averaging = :plane, filter_ratio = 3, cs_max = 0.5, mask = nothing) -> νt

Eddy viscosity $ν_t = C_s^2 Δ^2 |S|$ with the coefficient computed from the resolved field by the dynamic procedure of Germano et al. (1991) in the least-squares form of Lilly (1992). With a test filter $\widetilde{·}$ (here the 3 × 3 × 3 box average of cell-centred quantities),

\[L_{ij} = \widetilde{u_i u_j} - \tilde u_i \tilde u_j, \qquad M_{ij} = 2Δ^2\left(\widetilde{|S| S_{ij}} - α^2 |\tilde S| \tilde S_{ij}\right), \qquad C_s^2 = \frac{⟨L^d_{ij} M_{ij}⟩}{⟨M_{ij} M_{ij}⟩},\]

with $L^d$ the deviatoric part of $L$, $Δ = (Δx Δy Δz)^{1/3}$ and $α = \hat Δ / Δ$ the test-to-grid filter width ratio (filter_ratio). $C_s^2$ is clipped to $[0, c_{s,\max}^2]$ (no backscatter).

  • averaging = :plane — $⟨·⟩$ is the average over each horizontal level (Lilly 1992; the standard choice with horizontally homogeneous statistics), so $C_s$ depends on height only;
  • averaging = :local — the pointwise ratio (no averaging), which is noisy and relies on the clip.

filter_ratio: a discrete box of three cells has second moment $2Δ^2/3$; adding it to the implicit grid filter ($Δ^2/12$) gives an effective width $\sqrt{Δ^2 + 12·2Δ^2/3} = 3Δ$, hence the default 3. The value 2, often quoted for the 3-point trapezoidal filter, is the other common choice (see Lund 1997, Annual Research Briefs, CTR).

mask (optional; a Bool array the size of the cell-centred storage, true = solid, e.g. IBM.SolidMask.mask, whose halos are used as given) makes the procedure aware of immersed obstacles (P54-b, #173): the velocity is read with the no-slip value 0 on every face touching a solid (so whatever is stored inside an obstacle never reaches a fluid cell), the test filter is the masked box of box_filter! (fluid neighbours only, renormalised by their number), the plane average runs over the fluid cells of each level, and $C_s^2 = ν_t = 0$ in solid cells.

The strain rate uses the stencil of compute_smagorinsky_νt!, so for a fixed $C_s^2$ the two agree exactly. Halos of u, v, w must be filled and be at least 2 wide (the strain rate is evaluated on one shell of halo cells so the test filter reaches every interior cell). The coefficient is left in workspace.cs2.

References: Germano, Piomelli, Moin & Cabot (1991), Phys. Fluids A 3, 1760; Lilly (1992), Phys. Fluids A 4, 633.

Aeolus.Operators.DynamicSmagorinskyWorkspace — Type
DynamicSmagorinskyWorkspace(mesh)

Scratch storage for compute_dynamic_smagorinsky_νt!: the cell-centred velocity and strain-rate components on the interior plus one shell, and cs2, the interior-sized coefficient $C_s^2$ of the last call (a diagnostic).

Aeolus.Operators.add_eddy_viscosity_u! — Function
add_eddy_viscosity_u!(tu, u, νt; weights = nothing)

Add the conservative eddy-viscosity tendency ∂/∂xⱼ(νₜ ∂uᵢ/∂xⱼ) to the face-centered momentum tendencies. νt is interpolated from cell centers to the flux face (edges for off-diagonal fluxes).

weights = (Wc, Wf) is the sound-proof form (1/W) ∂ⱼ(W νₜ ∂uᵢ/∂xⱼ), with a cell weight Wc[k] and a bottom-z-face weight Wf[k] per storage level (Anelastic.constraint_weights, ONE-j #460): only the vertical fluxes are weighted (W depends on z), and Σ W uᵢ ΔV is conserved instead of Σ uᵢ ΔV. nothing (default) is the unweighted operator, bit for bit.

Aeolus.Operators.add_eddy_diffusion_scalar! — Function
add_eddy_diffusion_scalar!(tϕ, ϕ, κt::Field; mask = nothing, weights = nothing)
add_eddy_diffusion_scalar!(tϕ, ϕ, νt::Field, Pr_t)
add_eddy_diffusion_scalar!(tϕ, ϕ, κh::Field, κv::Field; mask = nothing, weights = nothing)

Add the conservative eddy-diffusion tendency ∂/∂xⱼ(κₜ ∂ϕ/∂xⱼ) to the cell-centred scalar tendency tϕ, with the cell-centred diffusivity κt averaged linearly to each face. The four-argument form with a number is (1/Prₜ) ∂/∂xⱼ(νₜ ∂ϕ/∂xⱼ): the same kernel, with the turbulent Prandtl number applied as a factor after the flux divergence.

The form with two fields is the diagonal operator (P55-c, #181): ∂/∂x(κh ∂ϕ/∂x) + ∂/∂y(κh ∂ϕ/∂y) + ∂/∂z(κv ∂ϕ/∂z), κh on the x and y faces and κv on the z faces. It is the diffusivity tensor diag(κh, κh, κv); the three-argument isotropic form is its case κv = κh, bit for bit (one kernel). The general symmetric tensor is add_tensor_diffusion_scalar!. Halos of ϕ and of the coefficient fields must be filled.

Keywords of the three-argument form (P56-a, #177), also taken by the diagonal form (κh on the x, y faces and κv on the z faces, e.g. the coefficients of a stability-corrected closure, P55-e):

  • mask — a storage-sized AbstractArray{Bool,3} of solid cells (e.g. IBM.SolidMask(...).mask). A face with a solid cell on either side carries no flux, so a scalar does not diffuse into or out of a building, and the tendency of a solid cell is left untouched. Every open face carries the unmasked flux, so the fluid integral Σ ϕ dV is conserved exactly (up to round-off). The halo entries of mask must be consistent with the boundary conditions of ϕ (periodic copies across a periodic seam; a false halo next to a no-flux wall is harmless, since that face carries no gradient).
  • weights = (Wc, Wf) — the sound-proof (anelastic / pseudo-incompressible) form (1/W) ∇·(W κₜ ∇ϕ), with a cell weight Wc[k] and a z-face weight Wf[k] (bottom face of cell k) per storage level (Anelastic.constraint_weights). It conserves Σ W ϕ dV instead of Σ ϕ dV.

With both nothing (default) this is bit for bit the unmasked kernel.

Stratification (P58-a)

Pointwise fields of the TurbulenceStability contract.

Aeolus.Operators.buoyancy_frequency_squared! — Function
buoyancy_frequency_squared!(N2, θ; θ₀, g)
buoyancy_frequency_squared!(N2, θ, qv; θ₀, g)
buoyancy_frequency_squared!(N2, θ, qv, qc; θ₀, g, p)

Squared buoyancy frequency at cell centres,

\[N^2_k = \frac{g}{θ_0}\,\frac{θ_{v,k+1/2} - θ_{v,k-1/2}}{Δz},\]

the vertical difference of the buoyancy that add_buoyancy! applies at the two w faces of the cell: θ (and qv) are interpolated to the faces exactly as there, and with qv the virtual potential temperature $θ_v = θ(1 + 0.61 q_v)$ of the moist buoyancy is used (qv = nothing is the dry form). On a uniform grid this is the centred difference $(g/θ_0)(θ_{k+1} - θ_{k-1})/(2Δz)$. The difference itself is TurbulenceStability.buoyancy_frequency_squared.

Cloudy air (qc, #239). With a condensate field qc (cloud or fog water, kg kg⁻¹) the buoyancy variable is the density potential temperature with condensate loading, $θ_ρ = θ(1 + 0.61 q_v - q_c)$ (interpolated to the faces like θv), and in a saturated cell — one with ``qc > 0$, which after a saturation adjustment means$qv = qs$—$N^2$is the saturated buoyancy frequency, `MoistThermodynamics.saturated_buoyancy_frequency_squared` (Durran & Klemp 1982 in a saturated environment, with the virtual effect of the humidity jump kept at a cloud edge), from the same face differences of θ,$qv$and$qw = qv + qc$over Δz and the cell's own θ,$qv$,$qc$and pressure `p`. Moist-adiabatic (moist-neutral) saturated air then has$N^2 ≈ 0$($|N^2| < 10^{-10}$s⁻² at Δz = 12.5 m) instead of the$1.4 × 10^{-4}`s⁻² of the θ_v form (a 1 km column from 285 K). Whereqcis zero in a cell and both neighbours the result is theqv` form bit for bit.

p (Pa) is the pressure of the saturated adjustment: a number or a vector indexed by the storage level k (length Nz + 2Hz), like θ₀.

θ₀ is a number (the constant reference of the Boussinesq core) or a vector indexed by the storage level k of the cell (length Nz + 2Hz): the height-dependent reference $\bar θ(z)$ of the sound-proof cores, whose buoyancy is $g(θ - \bar θ)/\bar θ$ (ReferenceState.θ̄c_pad; used by StabilityCorrected, P55-e).

N2, θ (and qv, qc) live at CellCenter; the halos of θ, qv and qc must be filled (at a wall the mirror halo halves the boundary gradient). Interior cells only. Returns N2.

Aeolus.Operators.strain_rate_squared! — Function
strain_rate_squared!(S2, u, v, w)

$|S|^2 = 2 S_{ij} S_{ij}$ at cell centres, the strain-rate stencil of compute_smagorinsky_νt! and the $S^2$ of gradient_richardson!. Halos of u, v, w must be filled. Interior cells only. Returns S2.

Aeolus.Operators.gradient_richardson! — Function
gradient_richardson!(Ri, N2, u, v, w; S2_min = RI_SHEAR2_FLOOR)

Gradient Richardson number at cell centres, $Ri = N^2/\max(|S|^2, S^2_{\min})$ (TurbulenceStability.gradient_richardson), with $|S|^2 = 2 S_{ij} S_{ij}$ from the strain-rate stencil of compute_smagorinsky_νt! — the shear the Smagorinsky closure sees, so $K = (C_sΔ)^2 |S| f(Ri)$ is consistent. For a pure vertical shear $u(z)$ it is $(∂u/∂z)^2$ (centred over $2Δz$).

N2 is a CellCenter field from buoyancy_frequency_squared!; u, v, w live on the faces and their halos must be filled. Interior cells only. Returns Ri.

Advection schemes

Aeolus.Operators.advect_weno5! — Function
advect_weno5!(tend, u, v, w, ϕ)

Add -∂(uⱼϕ)/∂xⱼ to tend using WENO-5 upwind reconstruction. Non- oscillatory near sharp gradients — the recommended scheme for scalars (θ, tracers, moisture) once the domain has walls or fronts. Requires halo ≥ 3 in every direction.

Staggered case only: u, v, w @ Face…, ϕ, tend @ CellCenter.

Forcing terms

Aeolus.Operators.add_surface_flux! — Function
add_surface_flux!(tϕ, F_bot, F_top)

Inject prescribed diffusive fluxes at the bottom (F_bot) and top (F_top) walls of the domain into the cell-centered scalar tendency. Sign convention: F_bot > 0 means flux into the domain from below.

On a sound-proof core this is also the W-weighted flux form (W_f/W_c) F/Δz: the wall faces of a ReferenceState carry the weight of the adjacent cell (W_f = W_c there), so Σ W ϕ ΔV changes by (W_bot F_bot − W_top F_top) A exactly.

Aeolus.Operators.add_sponge! — Function
add_sponge!(tf, f, α_max, z_start, z_top; f_ref = 0)

Rayleigh damping toward f_ref in the region z ≥ z_start. Damping rate grows smoothly α(z) = α_max sin²(π/2 (z - z_start)/(z_top - z_start)). Adds -α(z)·(f - f_ref) to tf for cells inside the sponge region.

f_ref (#254) is

  • a number — the constant target of the Phase-7 velocity sponge;
  • a level vector of length Nz — one target per interior level of f's location, e.g. the initial θ̄(z) of a free-atmosphere top;
  • a Field or a halo-padded 3-D array of f's shape — a full 3-D target, e.g. the parent state a nest is damped toward.

A ForcingTable or a time-dependent profile is evaluated into a level vector by LargeScaleForcing.ReferenceDamping, which also books the tendency integral. A constant level vector gives the same tendency as the equal number, bit for bit.

The rate is damping_rate of sponge_profile(α_max, z_start, z_top), the damping-profile implementation the fringe region of Transition (P59-d) shares; the arithmetic is the one kernel FiniteVolume._add_damping! on a RegularGrid and a StretchedGrid.

References: Klemp, J. B. & Lilly, D. K. (1978), J. Atmos. Sci., 35, 78-107; Durran, D. R. (2010), Numerical Methods for Fluid Dynamics, 2nd ed., §8.4.

Damping profiles

The one implementation of relaxation rates, shared by the Rayleigh sponge (every mesh type, and the :cos2 nest sponge), the fringe region of Transition (P59-d, #185) and LargeScaleForcing.ReferenceDamping (N-parent-b, #254). The arithmetic is one kernel, FiniteVolume._add_damping!, on a RegularGrid and a StretchedGrid; its target is a number, a level vector, a Field or a 3-D array.

Aeolus.Operators.FiniteVolume.AbstractRamp — Type
AbstractRamp

Shape of a DampingProfile: SinSquaredRamp (Rayleigh sponge) or NordstromRamp (fringe region).

Aeolus.Operators.FiniteVolume.SinSquaredRamp — Type
SinSquaredRamp()

Rise-only ramp λ(ξ) = λ_max sin²(½π (ξ − ξ_start)/w) for ξ ≥ ξ_start (zero below). The shape of the Phase-7 Rayleigh sponge add_sponge!, whose width w is the distance from z_start to the domain top. Reference: Klemp, J. B. & Lilly, D. K. (1978), J. Atmos. Sci., 35, 78-107.

Aeolus.Operators.FiniteVolume.NordstromRamp — Type
NordstromRamp()

Rise-plateau-fall ramp of Nordström, Nordin & Henningson (1999), eq. (2.3),

λ(ξ) = λ_max [ S((ξ − ξ_start)/Δ_rise) − S((ξ − ξ_end)/Δ_fall + 1) ],

with the smooth step S(x) = 0 (x ≤ 0), 1/(1 + exp(1/(x − 1) + 1/x)) (0 < x < 1), 1 (x ≥ 1) — see smooth_step. Infinitely differentiable; zero outside [ξ_start, ξ_end].

Reference: Nordström, J., Nordin, N. & Henningson, D. (1999). The fringe region technique and the Fourier method used in the direct numerical simulation of spatially evolving viscous flows. SIAM J. Sci. Comput., 20(4), 1365-1393.

LES analysis toolbox (Phase 54)

Explicit filters, the isotropic energy spectrum and the isotropic random-field initialiser (see LES filtering & closure). The box filter is the test filter of the dynamic Smagorinsky model; the Fourier tools treat the interior as triply periodic.

Aeolus.Operators.box_filter! — Function
box_filter!(out, f, n = 3; mask = nothing) -> out

Top-hat (box) filter of f over n × n × n cells (or n = (nx, ny, nz), each odd), written to the interior of out. Works at any Location: the stencil is taken on the storage indices of f, so a FaceX field is averaged over neighbouring x-faces, and so on. out and f must be distinct fields at the same location; the halos of f must be filled and at least n ÷ 2 wide. The halos of out are not touched.

Without a mask the result is the plain average $\bar f_{ijk} = n^{-3} \sum f$, which preserves the domain mean of a periodic field. Its second moment is $(n^2-1)Δ^2/12$ per direction, the quantity behind the default test-to-grid width ratio of compute_dynamic_smagorinsky_νt! (Lund 1997).

mask (a Bool array the size of f.data, true = solid, at the location of f; see staggered_solid_mask) restricts the average to fluid neighbours and renormalises by their number,

\[\bar f_{ijk} = \frac{\sum_{\text{fluid}} f}{N_{\text{fluid}}},\]

so values inside obstacles never enter the result. Solid cells (and cells with no fluid neighbour) get 0.

This is the test filter of the dynamic Smagorinsky model (Germano et al. 1991); compute_dynamic_smagorinsky_νt! uses the same stencil sum.

Reference: Lund, T. S. (1997), On the use of discrete filters for large eddy simulation, CTR Annual Research Briefs, 83.

Aeolus.Operators.staggered_solid_mask — Function
staggered_solid_mask(mask, loc::Location) -> BitArray

The solid mask at a staggered location from a cell-centre mask (true = solid, the storage-sized array of an IBM.SolidMask or CutCell.solid_mask): a face is solid when either cell it separates is solid, the rule of IBM.apply_solid_mask!. For CellCenter() a copy of mask is returned. The outermost storage layer, whose upwind neighbour does not exist, copies the cell mask.

Aeolus.Operators.gaussian_filter! — Function
gaussian_filter!(out, f, Δ) -> out

Gaussian filter of width Δ (a length, or (Δx, Δy, Δz)) applied in Fourier space, with the transfer function (Pope 2000, table 13.2)

\[\hat G(\mathbf k) = \exp\!\left(-\frac{k_x^2 Δ_x^2 + k_y^2 Δ_y^2 + k_z^2 Δ_z^2}{24}\right),\]

i.e. $\exp(-k^2Δ^2/24)$ for an isotropic width, the kernel with the same second moment $Δ^2/12$ as a top hat of width $Δ$. The interior of f is treated as triply periodic (FFTW); halos are ignored and those of out are not written. Any Location works, the filter acting on the stored samples. The mean ($k = 0$) is preserved exactly.

Reference: Pope, S. B. (2000), Turbulent Flows, §13.2.

Aeolus.Operators.spectral_cutoff_filter! — Function
spectral_cutoff_filter!(out, f, k_c) -> out

Sharp spectral filter: removes every Fourier mode of the (triply periodic) interior of f with $|\mathbf k| > k_c$ (angular wavenumber, rad m⁻¹) and keeps the rest unchanged. The filter is a projection, so it is idempotent; the mean is preserved. The natural cut-off of an $N$-point grid is $k_c = π/Δ$ (Pope 2000, §13.2); the LES resolution of a grid twice as coarse is $k_c = π/(2Δ)$.

Aeolus.Operators.isotropic_energy_spectrum — Function
isotropic_energy_spectrum(u, v, w; Δk = 2π / max(Lx, Ly, Lz)) -> (k, E)

Shell-summed kinetic-energy spectrum of a triply periodic velocity field. Each component u, v, w (staggered FaceX/FaceY/FaceZ or all CellCenter) is Fourier transformed on its own grid (FFTW rfft of the interior; halos are not used). The staggering only shifts the phase of a mode, so no interpolation is needed, and none is done: a two-point average to cell centres would damp mode $\mathbf k$ by $\prod_j \cos^2(k_jΔ_j/2)$, a filter that vanishes at the cut-off. The energy $\tfrac12 |\hat{\mathbf u}(\mathbf k)|^2$ of every mode is added to the shell $n = \mathrm{round}(|\mathbf k|/Δk)$, and

\[E(k_n) = \frac{1}{Δk} \sum_{n - 1/2 \,≤\, |\mathbf k|/Δk \,<\, n + 1/2} \tfrac12 |\hat{\mathbf u}(\mathbf k)|^2, \qquad k_n = nΔk,\]

normalised so that $\sum_n E(k_n)\,Δk = \tfrac12⟨u_i u_i⟩$ exactly (Parseval), the average taken over the stored (face) values, i.e. the kinetic energy of kinetic_energy(sim) divided by the volume. k runs from 0 (the mean flow, shell 0) to the shell of the corner mode, in rad m⁻¹; E is in m³ s⁻². Unit-width ($Δk$) bins are the standard of Rogallo (1981) and Pope (2000, §6.5).

References: Rogallo, R. S. (1981), Numerical experiments in homogeneous turbulence, NASA TM 81315; Pope, S. B. (2000), Turbulent Flows, ch. 6.

Aeolus.Operators.isotropic_random_field! — Function
isotropic_random_field!(u, v, w, E; rng = Random.default_rng(), kmax) -> (u, v, w)
isotropic_random_field!(sim, E; rng, kmax) -> sim

Fill the staggered velocity u @ FaceX, v @ FaceY, w @ FaceZ (interior) with a solenoidal, random-phase, triply periodic field whose isotropic_energy_spectrum is E(k) ($k$ in rad m⁻¹, $E$ in m³ s⁻²) in every shell $1 ≤ n ≤ k_{max}/Δk$, and zero above. The sim method writes sim.u, sim.v, sim.w and fills their halos with sim.bcs.

Construction (Rogallo 1981, adapted to the C-grid). For every Fourier mode a complex Gaussian vector $\hat b(\mathbf k)$ is drawn and projected so that the discrete staggered divergence vanishes: for face values with Fourier amplitude $a_j = \hat b_j e^{-ik_jΔ_j/2}$ the divergence $(u_{i+1} - u_i)/Δx + …$ has amplitude $2i\sum_j \hat b_j \sin(k_jΔ_j/2)/Δ_j$, so $\hat b$ is projected normal to $S_j = \sin(k_jΔ_j/2)/Δ_j$ (→ $k_j/2$ as $k_jΔ_j → 0$, the continuous projection). Hermitian symmetry is imposed and every shell is rescaled to hold exactly $E(k_n)Δk$ of face energy ($|a_j| = |\hat b_j|$). Modes on a Nyquist plane are left empty. The result is divergence-free to round-off under the C-grid divergence of the pressure projection, so no projection step is needed before a run, and its kinetic energy (kinetic_energy(sim)/volume) is $\sum_n E(k_n)Δk$.

kmax defaults to the largest sphere inside the grid, $\min_j π/Δ_j$.

References: Rogallo, R. S. (1981), NASA TM 81315; Kang, Chester & Meneveau (2003), J. Fluid Mech. 480, 129 (the same construction on a collocated grid for the Comte-Bellot–Corrsin initial condition).

Aeolus.Operators.rescale_to_spectrum! — Function
rescale_to_spectrum!(u, v, w, E; kmax) -> (u, v, w)

Multiply every Fourier shell of the staggered, triply periodic velocity u @ FaceX, v @ FaceY, w @ FaceZ by the factor that makes its isotropic_energy_spectrum equal to E(k) (shells $1 ≤ n ≤ k_{max}/Δk$; the mean and the shells above are zeroed). Phases, and hence the triadic correlations a run has built, are kept; the scaling is per Fourier mode, so a field that is discretely divergence-free stays so. Halos are not filled.

This is the "evolve and rescale" preparation of an initial field with realistic phases (Rogallo 1981; used for the Comte-Bellot–Corrsin case by Kang, Chester & Meneveau 2003): a random-phase field has the right spectrum but no energy transfer, and relaxes for about one eddy turnover before the cascade is established.

Aeolus.Operators.subfilter_stress! — Function
subfilter_stress!(τ, u, v, w, filter; ubar = nothing, bcs = periodic,
                  velocity_bcs = nothing) -> τ

The exact subfilter (SGS) stress of a resolved velocity field under an explicit filter $\overline{\,·\,}$,

\[τ_{ij} = \overline{u_i u_j} - \bar u_i \bar u_j ,\]

at the interior cell centres, written into τ::SymmetricTensorField. u, v, w are staggered (FaceX/FaceY/FaceZ; interpolated to centres by the periodic two-point average of isotropic_energy_spectrum, or, with velocity_bcs — the velocity boundary conditions of an open domain, N-open-d #262 — the average with the far face read through BoundaryConditions.neighbor_index) or all CellCenter. filter is any callable filter(out, f) acting on CellCenter fields, e.g.

(o, f) -> gaussian_filter!(o, f, 4h)       # Gaussian, Δ = 4h
(o, f) -> box_filter!(o, f, 5)             # top hat over 5 cells
(o, f) -> spectral_cutoff_filter!(o, f, kc)

The halos of every field handed to filter are filled with bcs (triply periodic by default), so stencil filters work too. With ubar = (ū, v̄, w̄) (three CellCenter fields) the filtered velocity is returned as well.

For a filter with a positive kernel $τ_{ij}$ is a covariance of the velocity under the kernel weights and hence positive semi-definite at every point (Vreman, Geurts & Kuerten 1994); it is Galilean invariant for any filter that preserves constants (Speziale 1985).

References: Leonard, A. (1974), Adv. Geophys. 18A, 237; Vreman, B., Geurts, B. & Kuerten, H. (1994), J. Fluid Mech. 278, 351; Pope, S. B. (2000), Turbulent Flows, §13.3.

Aeolus.Operators.bardina_stress! — Function
bardina_stress!(τ, ū, v̄, w̄, filter; C_B = 1, bcs = periodic) -> τ

Scale-similarity model of Bardina, Ferziger & Reynolds (1980): the subfilter stress of the filtered field under the same filter,

\[τ^{B}_{ij} = C_B\left(\overline{\bar u_i \bar u_j} - \bar{\bar u}_i \bar{\bar u}_j\right),\]

i.e. subfilter_stress! applied to ū, v̄, w̄ (CellCenter). A reference model for a-priori comparisons only: it correlates well with the exact stress (Liu, Meneveau & Katz 1994 measure $ρ ≈ 0.6–0.8$ against $≈ 0.2–0.4$ for Smagorinsky) but dissipates too little to run on its own, so it is not offered as a closure.

References: Bardina, J., Ferziger, J. H. & Reynolds, W. C. (1980), AIAA paper 80-1357; Liu, S., Meneveau, C. & Katz, J. (1994), J. Fluid Mech. 275, 83.

Aeolus.Operators.sgs_dissipation — Function
sgs_dissipation(τ, S̄::SymmetricTensorField) -> Π
sgs_dissipation(τ, (ū, v̄, w̄)) -> Π

Pointwise SGS dissipation (the resolved-to-subfilter energy transfer)

\[Π = -τ_{ij}\bar S_{ij},\]

positive for forward scatter. Only the deviatoric part of $τ$ is used (the isotropic part does no work against a solenoidal strain; using it would add the round-off $τ_{kk}\bar S_{ii}/3$ of the discrete divergence). The second form computes $\bar S$ with filtered_strain. For the Smagorinsky model $Π = (C_sΔ)^2|\bar S|^3 ≥ 0$ everywhere.

Aeolus.Operators.lumley_invariants — Function
lumley_invariants(τ::SymmetricTensorField) -> (II, III)

Pointwise invariants of the anisotropy tensor $b_{ij} = τ_{ij}/τ_{kk} - δ_{ij}/3$ (Lumley 1978): $II = b_{ij}b_{ji}$, $III = b_{ij}b_{jk}b_{ki}$. A realizable (positive semi-definite) stress lies in the Lumley triangle, $0 ≤ II ≤ 2/3$; in Pope's variables $η^2 = II/6$, $ξ^3 = III/6$ it is bounded by the axisymmetric lines $|ξ| = η$ and the two-component line $η^2 = 1/27 + 2ξ^3$. Points with $τ_{kk} ≤ 0$ give NaN.

Reference: Lumley, J. L. (1978), Adv. Appl. Mech. 18, 123; Pope, S. B. (2000), Turbulent Flows, §11.3.

Aeolus.Operators.apriori_metrics — Function

Standard a-priori comparison of a model stress with the exact subfilter stress on the same filtered field (Clark, Ferziger & Reynolds 1979; Liu, Meneveau & Katz 1994). All averages are volume averages over the interior.

  • ρ — per-component correlation coefficients of the deviatoric stresses, a NamedTuple (xx, yy, zz, xy, xz, yz); an eddy-viscosity model is deviatoric by construction, so the trace, which it does not predict, is removed from both.
  • ρ_offdiag — the mean of the three off-diagonal correlations.
  • ρ_Π — correlation of the pointwise dissipations $Π = -τ_{ij}\bar S_{ij}$ (see sgs_dissipation).
  • Π_ratio — $⟨Π_{model}⟩/⟨Π_{exact}⟩$, the net energy-transfer ratio.
  • backscatter_exact, backscatter_model — the fraction of points with $Π < 0$.
  • Π_exact, Π_model — the mean dissipations.
  • II, III — volume means of the Lumley invariants of the exact stress (lumley_invariants); realizable — the fraction of points of the exact stress inside the Lumley triangle.

FFT planning policy

The one place the FFTW planner flag and thread count of every FFT plan (the pressure solvers, the diagnostics) are chosen (#245). Default :measure, :patient opt-in; the test suite uses :estimate. Why it matters for restarts: Checkpoint / restart and FFT planning.

Aeolus.Operators.set_fftw_policy! — Function
set_fftw_policy!(; planner = nothing, threads = nothing) -> NamedTuple

Set the FFTW planning policy every FFT plan of Aeolus is made with (the pressure solvers' and the diagnostics'): planner is :estimate, :measure (the default), :patient or :exhaustive, and threads the FFTW thread count (FFTW.set_num_threads). :patient finds somewhat faster plans at a much higher planning cost — measured at 256³: 494 s of planning with :patient against 2.4 s with :measure, for transforms of 153 vs 182 ms — so it is worth opting into only for long runs. Plans made before the call keep their flags; set the policy before constructing a simulation.

The default can also be set from the environment, before the first plan: AEOLUS_FFTW_PLANNER=estimate, AEOLUS_FFTW_THREADS=4. The test suite sets AEOLUS_FFTW_PLANNER=estimate, so its bitwise comparisons hold across processes and planning stays fast. A TOML namelist sets it with an [fftw] table (apply_fftw_config!).

Threads. Without an explicit count the policy starts at one thread and init_threads! raises it to Threads.nthreads() (KA-h, #298). A count set here, through AEOLUS_FFTW_THREADS or by a namelist is explicit, and init_threads! keeps it. FFTW's threaded plans hand whole 1-D transforms to the threads, so under :estimate a solve gives identical bits at every FFTW thread count (measured for every pressure solver and axis-BC combination, 1-24 threads, docs/src/design/ka_port.md). Under the timing planners the planner may pick a different algorithm for a different thread count (as it may for another process), so there it holds only with imported wisdom made at the same thread count.

Reproducibility. :measure, :patient and :exhaustive time candidate algorithms, so two processes may choose different plans and differ in the last bit (FFTW FAQ 3.8); :estimate is deterministic, and so is any planner whose plans come from imported wisdom (load_fftw_wisdom!). fftw_policy reports which case holds. Returns the new fftw_policy.

References

  • Frigo, M. & Johnson, S. G. (2005). The design and implementation of FFTW3. Proc. IEEE, 93, 216-231.
  • FFTW FAQ, question 3.8: "FFTW gives different results between runs".
