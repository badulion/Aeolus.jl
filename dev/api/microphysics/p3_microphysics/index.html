P3 microphysics (Phase 40)

P3Microphysics implements the Morrison–Milbrandt predicted-particle- properties scheme. Its size-distribution integrals rest on the in-package gamma and regularised incomplete gamma functions documented here; its sedimentation (one fall speed per moment, Courant sub-stepping) and radar reflectivity (rain Rayleigh $Z$, ice equivalent $Z_e$) are the observables it is validated with. Secondary ice from Hallett–Mossop rime splintering is driven by its riming rates. Theory: P3 microphysics.

The module's API is large, so it is split by topic over three pages:

  • this page — the module, gamma functions and gamma size-distribution moments, and the mass–dimension relation across the rime regimes with what follows from it: the ice parameters (P3IceParameters), the ice size distribution and slope, and the single-particle and bulk ice fall speeds (p3_fall_speed, p3_bulk_fall_speed);
  • P3 process rates and secondary ice — the process rates, the time step (p3_tendencies, p3_step) and Hallett–Mossop rime splintering;
  • P3 sedimentation, reflectivity and precipitation fraction — per-moment sedimentation, radar reflectivity, and the Phase 44 sub-grid precipitation fraction.

Terminal-velocity spectrum and precipitation fraction (Phase 44)

The Kessler scheme's rain now falls at the mass-weighted speed of its Marshall–Palmer spectrum (kessler_fall_speed, in Aeolus.Microphysics, see Physics modules), and P3 gains a sub-grid precipitation fraction carried down the column with maximum, random or maximum-random overlap (p3_precipitation_fraction, p3_fractional_process_rates, p3_step_column), documented on P3 sedimentation, reflectivity and precipitation fraction. Theory: P3 microphysics, last section.

Gamma functions, mass–dimension relation and ice fall speed

Aeolus.P3Microphysics — Module
P3Microphysics

Predicted Particle Properties (P3) bulk microphysics — Phase 40.

P3 (Morrison & Milbrandt 2015) replaces the traditional split of ice into fixed categories (cloud ice, snow, graupel, hail) with a single ice category whose properties evolve: prognostic rime mass and rime volume give a continuously varying bulk density, and the mass-dimension relation switches between four regimes (small spheres, unrimed aggregates, graupel, partially rimed) with thresholds diagnosed from the rime fraction.

Particle size distributions are complete gamma distributions,

N(D) = N₀ D^μ exp(-λ D),

so every bulk quantity (mass, reflectivity, sedimentation flux) is a moment — full or truncated over one mass-dimension regime — expressed through the gamma and regularised incomplete gamma functions.

LAYOUT

The module is split into part-files under src/p3/:

  • gamma.jl — log-gamma (Lanczos), gamma, regularised incomplete gamma P/Q, gamma-PSD moments (full and truncated)
  • massdim.jl — four-regime m(D), A(D), rime density, fall speed
  • processes.jl — microphysical process rates
  • sedimentation.jl — sedimentation and radar reflectivity
  • precip_fraction.jl — sub-grid precipitation fraction and overlap
  • secondary.jl — Hallett–Mossop rime splintering, nucleated-ice mass

Thermodynamics (saturation vapour pressures, latent heats, saturation adjustment) is NOT re-derived here: it comes from the shared core MoistThermodynamics.

REFERENCES

  • Morrison, H. & Milbrandt, J. A. (2015). Parameterization of cloud microphysics based on the prediction of bulk ice particle properties. Part I. J. Atmos. Sci., 72, 287-311.
  • Milbrandt, J. A. & Morrison, H. (2016). Part III: Introduction of multiple free categories. J. Atmos. Sci., 73, 975-995.
  • Press, W. H. et al. (2007). Numerical Recipes, 3rd ed., §6.1-6.2.
Aeolus.P3Microphysics.gamma_inc_lower — Method
gamma_inc_lower(a, x)

Regularised lower incomplete gamma function P(a,x) = γ(a,x)/Γ(a), a > 0, x ≥ 0. See gamma_inc_pq.

Aeolus.P3Microphysics.gamma_inc_pq — Method
gamma_inc_pq(a, x) -> (P, Q)

Regularised lower and upper incomplete gamma functions

P(a,x) = γ(a,x)/Γ(a) = (1/Γ(a)) ∫₀ˣ t^{a-1} e^{-t} dt
Q(a,x) = Γ(a,x)/Γ(a) = 1 - P(a,x)

for a > 0, x ≥ 0 (x = Inf allowed).

P is computed directly by the power series for x < a + 1, and Q by the Lentz-evaluated continued fraction otherwise. The other value is the complement. The tail that can become very small (P for x ≪ a, Q for x ≫ a) is therefore always computed directly and keeps its relative accuracy. Measured against MPFR for 1 ≤ a ≤ 100, the smaller tail's error is at most 1.0e-13 relative (at a = 40, x = 1e-4, where P ≈ 1e-208 and the a log x term in the prefactor dominates).

Limitation for a < 1. For x < 1, Q(a,x) is of order a and is formed as 1 - P, so its relative error grows like eps/Q:

aQ(a, 0.99) relative error
0.14.7e-15
1e-31.8e-12
1e-64.2e-9

P3 only needs a = μ + k + 1 ≥ 1, so this range is never reached there. For large a the error in the x^a e^{-x}/Γ(a) prefactor grows too, to about 2e-13 at a = 500 and 2e-11 at a = 10⁴, both near x = a.

P(a,x) is the CDF of a Gamma(a,1) variate; for a gamma size distribution N(D) ∝ D^μ e^{-λD} the fraction of the k-th moment carried by particles smaller than D is P(μ+k+1, λD).

Named gamma_inc_pq rather than gamma_inc because SpecialFunctions.gamma_inc is exported under that name; both being exported would make the bare name ambiguous in user code that loads both packages.

Reference: Press et al. (2007), Numerical Recipes 3rd ed., §6.2 (gammp, gammq, gser, gcf).

Aeolus.P3Microphysics.gamma_inc_upper — Method
gamma_inc_upper(a, x)

Regularised upper incomplete gamma function Q(a,x) = Γ(a,x)/Γ(a) = 1 - P(a,x), a > 0, x ≥ 0. See gamma_inc_pq.

Aeolus.P3Microphysics.gamma_lanczos — Method
gamma_lanczos(x)

The gamma function Γ(x) for real x.

  • positive integers n ≤ 171: (n-1)! by direct product (exact up to n = 23 in Float64);
  • other x > 0: exp(lgamma_lanczos(x));
  • negative non-integers: reflection, Γ(x) = π / (sin(πx) Γ(1-x));
  • non-positive integers are poles and raise a DomainError.

Overflows to Inf for x > 171.62 in Float64.

Reference: Press et al. (2007), Numerical Recipes 3rd ed., §6.1.

Aeolus.P3Microphysics.gamma_psd_density — Method
gamma_psd_density(D, N0, μ, λ)

Number density of the complete gamma particle size distribution,

N(D) = N₀ D^μ exp(-λD),

per unit diameter: m⁻⁴ when N is per m³ of air, so N₀ is in m⁻⁴⁻μ. P3 carries number per kg of air, which gives kg⁻¹ m⁻¹⁻μ. D diameter [m], μ shape parameter (dimensionless, μ > -1), λ slope [m⁻¹].

Reference: Morrison & Milbrandt (2015, JAS 72, 287-311), eq. 1.

Aeolus.P3Microphysics.gamma_psd_intercept — Method
gamma_psd_intercept(N, μ, λ)

Intercept N₀ of the gamma size distribution that has total number concentration N = M₀ for the given shape μ and slope λ:

N₀ = N λ^{μ+1} / Γ(μ+1).

Evaluated in log space.

Aeolus.P3Microphysics.gamma_psd_moment — Method
gamma_psd_moment(N0, μ, λ, k)

k-th moment of the gamma size distribution over 0 ≤ D < ∞,

M_k = ∫₀^∞ D^k N₀ D^μ e^{-λD} dD = N₀ Γ(μ+k+1) / λ^{μ+k+1},

requiring μ + k + 1 > 0. M₀ is the total number, M₃·(π/6)ρ the mass of spheres of density ρ, M₆ the Rayleigh reflectivity factor. Evaluated in log space so that large λ^{μ+k+1} (λ ~ 10⁴-10⁵ m⁻¹ is routine for cloud ice) cannot overflow before the division.

Reference: Morrison & Milbrandt (2015), §2; Seifert & Beheng (2006).

Aeolus.P3Microphysics.gamma_psd_partial_moment — Method
gamma_psd_partial_moment(N0, μ, λ, k, D1, D2)

k-th moment of the gamma size distribution truncated to D1 ≤ D ≤ D2 (D2 = Inf allowed),

∫_{D1}^{D2} D^k N₀ D^μ e^{-λD} dD
    = N₀ Γ(a)/λ^a · [P(a, λD₂) - P(a, λD₁)],   a = μ+k+1.

P3 needs these because the mass-dimension and area-dimension relations are piecewise power laws: each bulk integral splits into one truncated moment per regime (Morrison & Milbrandt 2015, §2b and Appendix).

When the interval lies in the upper tail (λD₁ > a) the difference is taken as Q(a, λD₁) - Q(a, λD₂) instead, so a small tail contribution does not vanish into the cancellation of two numbers near one.

The result is never negative. For an interval much narrower than the distribution (λ(D₂-D₁) ≲ 1e-8) the difference of two O(1) values keeps only about eps/(λ(D₂-D₁)) relative accuracy; the absolute error stays at the 1e-16 × M_k level.

Aeolus.P3Microphysics.gamma_psd_slope — Method
gamma_psd_slope(Mi, i, Mj, j, μ)

Slope λ of the gamma size distribution consistent with two of its moments, Mi = M_i and Mj = M_j (i ≠ j, orders need not be integers), for fixed shape μ:

M_i / M_j = Γ(μ+i+1)/Γ(μ+j+1) · λ^{j-i}
⇒ λ = [ (M_i/M_j) · Γ(μ+j+1)/Γ(μ+i+1) ]^{1/(j-i)}.

With i = 0 (number) and j = b (the mass exponent of a power-law m = αD^b, with M_b = q/α) this is the standard two-moment closure for λ (e.g. Seifert & Beheng 2006; Morrison & Milbrandt 2015, §2).

Both moments must be strictly positive: at q → 0 or N → 0 the slope is undefined and a DomainError is thrown, so callers apply the usual small-mixing-ratio threshold before diagnosing the PSD.

Aeolus.P3Microphysics.lgamma_lanczos — Method
lgamma_lanczos(x)

Natural logarithm of the absolute value of the gamma function, log |Γ(x)|, for real x.

For x ≥ 1/2 the 14-term Lanczos approximation of Press et al. (2007, Numerical Recipes 3rd ed., §6.1, gammln) is used (relative error of the Lanczos series < 1e-15). For x < 1/2 Euler's reflection formula

Γ(x) Γ(1-x) = π / sin(πx)

maps the argument into the Lanczos range. Non-positive integers are poles and return Inf.

Named with a _lanczos suffix so that it does not clash with SpecialFunctions.loggamma in user code that loads both packages.

Aeolus.P3Microphysics.p3_air_viscosity — Method
p3_air_viscosity(T) -> Pa s

η(T) = 1.458e-6 T^{3/2} / (T + 110.4),

Aeolus.P3Microphysics.p3_bulk_density — Method
p3_bulk_density(μ, λ, md::P3MassDimension) -> kg m⁻³

Bulk density of the ice population: total mass divided by the total volume of the circumscribing spheres of diameter D,

ρ_bulk = q_i / ((π/6) ∫ D³ N(D) dD) = (q/N) / ((π/6) M₃/M₀).

Equals ρ_ice for a population of small spheres, ρ_g for pure graupel, and falls towards the aggregate density 6α_va D^{β-3}/π for large unrimed snow.

Aeolus.P3Microphysics.p3_bulk_fall_speed — Method
p3_bulk_fall_speed(μ, λ, md::P3MassDimension; ρ_air, η_air) -> (V_N, V_M)

Number- and mass-weighted mean fall speeds (m s⁻¹) of the gamma size distribution N(D) ∝ D^μ e^{-λD},

V_N = ∫ V(D) N(D) dD / ∫ N(D) dD
V_M = ∫ V(D) m(D) N(D) dD / ∫ m(D) N(D) dD,

the sedimentation velocities of N_i and of q_i (and of q_rim, B_rim, which fall with the mass; MM15 §2d). V(D) from p3_fall_speed is not a power law, so the integrals are taken by composite Gauss-Legendre quadrature split at the regime thresholds (P3 itself tabulates the same integrals offline). The mass-weighted integral of m(D) by the same quadrature reproduces the analytic truncated-moment value p3_mean_mass to 7e-15 (tests).

Aeolus.P3Microphysics.p3_fall_speed — Method
p3_fall_speed(D, md::P3MassDimension; ρ_air, η_air) -> m s⁻¹

Still-air terminal fall speed of a P3 ice particle of maximum dimension D (m), from its regime mass m(D) and projected area A(D) by the boundary-layer drag theory of Mitchell & Heymsfield (2005, JAS 62, 1637-1644), the formulation used to build the P3 lookup tables (create_p3_lookupTable_1.f90):

X  = 2 m g ρ_a D² / (A η²)                            (Best number)
Re = δ₀²/4 · [ (1 + 4√X/(δ₀²√C₀))^{1/2} - 1 ]² - a₀ X^{b₀}
V  = η Re / (ρ_a D),

with δ₀ = 5.83, C₀ = 0.6. The turbulence correction a₀ X^{b₀} is off by default (a₀ = b₀ = 0), as in the P3 reference lookup-table code ("neglect turbulent correction for aggregates"). MH05 fitted a₀ = 1.7e-3, b₀ = 0.8 to aggregates; applied to dense particles it outgrows the first term (at X ≈ 4e9), so V(D) of 900 kg m⁻³ graupel peaks near 2 cm and reaches zero before 5 cm. Set a0, b0 in P3IceParameters to use it for snow only. Air density ρ_air (kg m⁻³) and dynamic viscosity η_air (Pa s) default to 253.15 K, 600 hPa (air_density from MoistThermodynamics, p3_air_viscosity). Gravity is MoistThermodynamics.DEFAULT_CONSTANTS.grav.

In the Stokes limit (X → 0) the formula gives Re = X/(δ₀²C₀), 17.7 % above the exact sphere result X/24, a known property of the MH05 boundary-layer fit; 10-50 μm ice spheres fall within 15.8 % of Stokes' law (measured in the tests). Unrimed aggregates of 0.5-10 mm fall within 12.2 % of the Locatelli & Hobbs (1974) fit 0.8 D^0.16 (D in mm) at 1.2 kg m⁻³. With a nonzero a₀, Re is floored at zero where the correction would make it negative.

m(D) is continuous but A(D) jumps at the thresholds, so V(D) jumps there too, as in MM15. The bulk speeds (p3_bulk_fall_speed) are continuous in F_rim and ρ_rim.

Aeolus.P3Microphysics.p3_mass_dimension — Method
p3_mass_dimension(F_rim, ρ_rim, p = P3_DEFAULT_ICE) -> P3MassDimension

Solve for the P3 regime thresholds and graupel density given the rime fraction F_rim ∈ [0,1] and rime density ρ_rim (kg m⁻³). The four regimes of the mass-dimension relation (MM15 eqs. 1-6, Appendix) are

regimerangem(D)A(D)
1 small spherical iceD ≤ D_th(π/6) ρ_ice D³(π/4) D²
2 dense nonspherical (unrimed)D_th < D ≤ D_grα_va D^β_vaγ_va D^σ_va
3 graupelD_gr < D ≤ D_cr(π/6) ρ_g D³(π/4) D²
4 partially rimedD > D_crα_va/(1-F_rim) D^β_vaF_rim (π/4)D² + (1-F_rim) γ_va D^σ_va

Each threshold is where the neighbouring masses are equal, so m(D) is continuous:

D_th = (π ρ_ice / (6 α_va))^{1/(β_va-3)}
D_gr = (6 α_va / (π ρ_g))^{1/(3-β_va)}
D_cr = (6 α_va / (π ρ_g (1-F_rim)))^{1/(3-β_va)}.

The graupel density is the rime plus the unrimed mass that filled in between the rime, ρ_g = F_rim ρ_rim + (1-F_rim) ρ_d, where ρ_d is the mean density of unrimed aggregates over [D_gr, D_cr],

ρ_d = 6 α_va (D_cr^{β-2} - D_gr^{β-2}) / (π (β-2)(D_cr - D_gr)).

MM15 and the P3 reference code solve this coupled system by fixed-point iteration. It is in fact linear in ρ_g: with r = D_cr/D_gr = (1-F_rim)^{-1/(3-β)}, ρ_d = g ρ_g with g = (r^{β-2}-1)/((β-2)(r-1)) independent of ρ_g, so

ρ_g = F_rim ρ_rim / (1 - (1-F_rim) g),

evaluated here in closed form (without cancellation for small F_rim). As F_rim → 0, ρ_g → 2ρ_rim/3 for any β_va, and the graupel and partially rimed regimes collapse onto the aggregate one; at F_rim = 0 exactly, D_gr = D_cr = Inf and m(D) is the unrimed two-regime relation. At F_rim = 1, ρ_g = ρ_rim and D_cr = Inf.

Since ρ_g ≤ ρ_rim ≤ ρ_ice, the thresholds always satisfy D_th ≤ D_gr ≤ D_cr. ρ_rim is clamped to [ρ_rim_min, ρ_rim_max].

References: Morrison & Milbrandt (2015, JAS 72, 287-311), §2b and Appendix; Brown & Francis (1995); Mitchell (1996).

Aeolus.P3Microphysics.p3_mean_mass — Method
p3_mean_mass(μ, λ, md::P3MassDimension) -> kg

Mean particle mass q_i/N_i of a gamma size distribution N(D) ∝ D^μ e^{-λD} under the four-regime P3 mass-dimension relation,

q/N = Σ_regimes c_j ∫_{D_lo,j}^{D_hi,j} D^{b_j} D^μ e^{-λD} dD
      / ∫_0^∞ D^μ e^{-λD} dD,

each term a truncated gamma moment (gamma_psd_partial_moment), so the result is exact up to the incomplete-gamma accuracy. Strictly decreasing in λ, since m(D) is increasing in D.

Reference: Morrison & Milbrandt (2015), §2b and Appendix.

Aeolus.P3Microphysics.p3_particle_area — Method
p3_particle_area(D, md::P3MassDimension) -> m²

Projected area of an ice particle of maximum dimension D (m): a disc (π/4)D² for small spheres and graupel, the Mitchell (1996) aggregate relation γ_va D^σ_va for unrimed nonspherical ice, and for partially rimed ice the rime-fraction weighted blend F_rim (π/4)D² + (1-F_rim) γ_va D^σ_va (MM15, §2b).

Unlike the mass, A(D) is not continuous at the thresholds (the disc and aggregate relations are independent fits), exactly as in MM15. At fixed D it therefore jumps when a moving threshold D_gr(F_rim, ρ_rim) or D_cr crosses D. The bulk integrals over the size distribution are nevertheless continuous in F_rim and ρ_rim, since the jump location moves continuously.

The P3 reference lookup-table code (create_p3_lookupTable_1.f90) no longer uses the F_rim weighting for partially rimed ice: it interpolates the area linearly in mass between the aggregate and graupel relations, A = A_agg + (m - m_agg)(A_gr - A_agg)/(m_gr - m_agg), which makes A continuous at D_cr (the F_rim form is left there commented out). The F_rim form of MM15 is kept here; expect bulk fall speeds of partially rimed ice to differ from current P3 tables.

Aeolus.P3Microphysics.p3_rime_state — Function
p3_rime_state(q_i, q_rim, B_rim, p = P3_DEFAULT_ICE) -> (F_rim, ρ_rim, B_rim′)

Diagnose rime fraction and rime density from P3's prognostic variables: total ice mass q_i (kg kg⁻¹), rime mass q_rim (kg kg⁻¹) and rime volume B_rim (m³ kg⁻¹),

F_rim = q_rim / q_i          clamped to [0, 1]
ρ_rim = q_rim / B_rim        clamped to [ρ_rim_min, ρ_rim_max].

When the rime density has to be clamped, the rime volume is made consistent with it, B_rim′ = q_rim / ρ_rim, and returned so the caller can write it back (MM15, §2b); otherwise B_rim′ = B_rim.

Carrying the rime volume rather than a density is what lets density emerge: when two populations mix, or new rime of density ρnew is accreted (`qrim += dq,Brim += dq/ρnew`), the resulting density is the mass-weighted harmonic mean of the parts, exactly, with no rule needed for how densities combine.

With no ice (q_i ≤ 0) or no rime (q_rim ≤ 0) the rime fraction is zero and ρ_rim_default is returned for the (then irrelevant) density.

Reference: Morrison & Milbrandt (2015, JAS 72, 287-311), §2b.

Aeolus.P3Microphysics.p3_size_distribution — Method
p3_size_distribution(q_i, N_i, md::P3MassDimension; μ = 0, kwargs...) -> (N0, μ, λ)

Gamma size distribution parameters consistent with ice mass q_i and number N_i: λ from p3_slope (keyword arguments are passed on), then N₀ = N_i λ^{μ+1}/Γ(μ+1) (gamma_psd_intercept).

Aeolus.P3Microphysics.p3_slope — Method
p3_slope(q_i, N_i, md::P3MassDimension; μ = 0, λ_min = 1.0, λ_max = 1e8) -> λ

Slope λ (m⁻¹) of the gamma distribution with shape μ whose mean particle mass under the P3 mass-dimension relation equals q_i/N_i, i.e. the root of p3_mean_mass(μ, λ, md) = q_i/N_i.

Because m(D) is piecewise, there is no closed form (unlike the single power law case, gamma_psd_slope); the mean mass is strictly decreasing in λ, and the root is bracketed in [λ_min, λ_max] and found by Illinois-modified regula falsi in log λ to ~1e-14 relative. If q_i/N_i lies outside the range spanned by the bracket the nearer bound is returned; P3 then adjusts N_i to be consistent with the limited λ (MM15, §2b), which is the caller's job.

The default bracket [1, 1e8] m⁻¹ is only a numerical one (mean sizes (μ+1)/λ from 10 nm to 1 m for μ = 0); it is not P3's physical limiter. The P3 reference code (create_p3_lookupTable_1.f90) keeps the mean size (μ+1)/λ between 2 μm and 5 mm + 20 mm·F_rim², i.e.

λ_min = (μ+1) / (5e-3 + 2e-2 F_rim²),   λ_max = (μ+1) / 2e-6,

and a model using this function should pass those; _p3_ice_λ_limits returns them (the single place these numbers live). Near λ = 1 m⁻¹ the PSD is dominated by metre-sized particles, outside the range of the fall-speed and mass-dimension fits.

The shape parameter is held fixed here. MM15 diagnose μ from λ (Heymsfield 2003); a caller doing so iterates μ, λ jointly.

Reference: Morrison & Milbrandt (2015), §2b.
