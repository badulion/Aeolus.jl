Geometric multigrid pressure solver (Phase 29)

Aeolus.Multigrid.MGLevel — Type
MGLevel{T}

One level of the multigrid hierarchy. Arrays carry a single-cell halo so the 7-point stencil can be applied without branching at the boundary.

Fields cx, cy, cz hold the face coefficients of a variable-coefficient operator ∇·(c ∇φ); for the constant-coefficient Laplacian they are all one and the fast path is taken. part holds the per-plane partial sums of the level's canonical reductions (one entry per level k; KA-i, #303), so a solve allocates nothing.

Aeolus.Multigrid.MGPreconditionedCG — Type
MGPreconditionedCG(mesh; mg_kwargs..., tol, maxit)

Conjugate gradient with one multigrid V-cycle as the preconditioner. This is the most robust configuration: CG supplies the optimal Krylov acceleration and guards against a mildly non-symmetric or poorly-coarsened multigrid operator, while the V-cycle keeps the iteration count grid-independent.

Use this instead of a bare MultigridPoissonSolver when the coefficient field is strongly varying (cut cells, large density contrast).

Aeolus.Multigrid.MultigridPoissonSolver — Type
MultigridPoissonSolver(mesh; kwargs...)

Geometric-multigrid Poisson solver. Iteration count is independent of grid size, which is the reason to prefer it over CGPoissonSolver on large grids, stretched grids, and cut-cell geometry.

Keyword arguments:

kwargdefaultmeaning
bc_x, bc_y, bc_z:periodic, :periodic, :neumannper-axis BC
tol1e-10relative residual tolerance
maxcycles50cycle cap
nu12pre-smoothing sweeps
nu22post-smoothing sweeps
cycle:V:V or :W
fmgfalsestart from a full-multigrid (nested-iteration) initial guess
min_size4stop coarsening when any dimension reaches this
coeff_x/y/znothingface coefficients for ∇·(c∇φ)
rhs_scalenothingper-level factor s_k applied to the source ((s_k b)): solves s_k (Lφ)_k = s_k b_k

MultigridPoissonSolver(g::StretchedGrid; kwargs...) builds the stretched-z operator from these (see below).

The mesh dimensions do not need to be powers of two — coarsening stops on any axis that becomes odd, so the hierarchy degrades gracefully (semi-coarsening) rather than failing.

Aeolus.Multigrid.MultigridPoissonSolver — Method
MultigridPoissonSolver(g::StretchedGrid; kwargs...)
MGPreconditionedCG(g::StretchedGrid; kwargs...)

The multigrid solvers for the conservative stretched-z Poisson operator of a StretchedGrid (the divergence of the gradient of its ∂z stencils, #151). Multiplying row k by s_k = Δz_c[k]/Δ (any reference Δ; here the thinnest cell) turns it into the symmetric variable-coefficient form this module solves,

\[\frac{s_k}{Δx^2}δ_x^2φ + \frac{s_k}{Δy^2}δ_y^2φ + \frac{1}{Δ^2}\Big[c_{k+1}(φ_{k+1}-φ_k) - c_k(φ_k-φ_{k-1})\Big] = s_k b_k, \qquad c_k = \frac{Δ}{Δz_f[k]},\]

i.e. coeff_x = coeff_y = s_k, coeff_z = c_k and rhs_scale = s_k on a uniform grid of spacing Δ. Metrics from cell_thickness/center_spacing. Keyword arguments are those of the RegularGrid constructors (BCs, tolerance, cycles).

Convergence needs a hierarchy: coarsening requires all three dimensions to halve, so a level count with few factors of two (a parent grid uniform to 500 m, then stretched: 53 levels) leaves one level and the "multigrid" is a Gauss-Seidel smoother. The default solver of the Boussinesq core is therefore the direct StretchedPoissonSolver; this route is for a variable coefficient field the transform cannot diagonalise.

Aeolus.Multigrid._compute_residual! — Method
_compute_residual!(L, bcx, bcy, bcz)

r = b − Aφ on the interior of level L: the halo fill, then one launch (constant or variable coefficient). Returns L.r.

Aeolus.Multigrid._fill_halo! — Method
_fill_halo!(φ, bcx, bcy, bcz)

Fill the single-cell halo of a level array according to the per-axis boundary conditions. φ has size (nx+2, ny+2, nz+2); the interior is 2:nx+1 in each direction. The per-axis halo kernels of BoundaryConditions (KA-f, #297; one source with fill_halos!): :periodic wraps, :neumann mirrors, x then y then z.

Aeolus.Multigrid._is_singular — Method

True when the operator is singular, i.e. the constants are in its null space.

Aeolus.Multigrid._l2 — Method

L2 norm of the interior of a level array (canonical sum of squares).

Aeolus.Multigrid._project_mean! — Method
_project_mean!(L, a) -> a

Subtract the interior mean from the level array a of level L in place (null-space projection). The sum is the canonical plane sum of Backends.plane_partials! (KA-a, #294), the same at every thread count.

Aeolus.Multigrid._prolong_add! — Method
_prolong_add!(fine, coarse, bcx, bcy, bcz)

Trilinear prolongation of the coarse correction, added onto the fine solution. For a cell-centred grid the fine cell centre sits a quarter of a coarse cell from the coarse centre, giving the separable (3/4, 1/4) weights in each direction. The coarse halo fill, then one launch in which each fine cell writes itself.

Aeolus.Multigrid._restrict! — Method
_restrict!(coarse, fine, m = 0)

Full-weighting restriction for a cell-centred grid: each coarse cell takes the mean of the eight fine cells it contains. Exact on constants. Operates on fine.r − m → coarse.b, one launch in which each coarse cell writes itself. m is the mean of fine.r when the null space is projected out: subtracting it inside the restriction gives the bits of a projection of fine.r followed by the restriction, without the sweep that writes the projected fine.r (KA-i, #303).

Aeolus.Multigrid._restrict_coeff — Method
_restrict_coeff(cx, cy, cz, cnx, cny, cnz)

Coarsen variable face coefficients by averaging the four fine faces that tile each coarse face. Keeps the coarse operator consistent with the fine one (a "Galerkin-lite" coarsening) — important for cut-cell and density-weighted problems where a naive re-evaluation on the coarse grid would lose the fine-scale blocking information.

Aeolus.Multigrid._smooth_rbgs! — Method
_smooth_rbgs!(L, bcx, bcy, bcz, nsweeps)

Red-black Gauss-Seidel relaxation. Each sweep updates the even-parity cells then the odd-parity cells, so within a colour the updates are independent while still getting Gauss-Seidel's superior smoothing factor over Jacobi. Per colour: the halo fill, then one launch over that colour's cells only, half the level (KA-i, #303). The updates of a colour read only the other colour, so the result does not depend on the order the cells run in and equals the serial sweep bit for bit.

Aeolus.Multigrid.mg_solve! — Method
mg_solve!(solver, φ_out, rhs) -> NamedTuple

Solve Aφ = rhs on the finest level. φ_out and rhs are interior-sized (Nx, Ny, Nz) arrays. Returns (; cycles, residual, converged).

Aeolus.Multigrid.mg_vcycle! — Method
mg_vcycle!(solver, lev)

One multigrid cycle starting at level index lev (1 = finest). Recursive; does one recursive call for a V-cycle and two for a W-cycle.

For a singular operator the mean is projected out of the solution after each smoothing and after the prolongation, out of the residual and out of the coarse right-hand side (canonical sums: the same at every thread count). The residual's mean is subtracted inside the restriction instead of in a sweep over the residual (KA-i, #303; fusing the sums into the stencil launches themselves measured slower, ka_port.md).

Aeolus.PressureSolvers.solve! — Method
solve!(p, source, solver::MGPreconditionedCG)

CG preconditioned by mg_cycles V-cycles, through the one CG driver Aeolus.Backends.pcg! (KA-g, #300): canonical reductions, so a solve and its iteration count are identical at every thread count. For a singular operator (periodic / Neumann on every axis) the mean is removed from the source, from every preconditioned residual and from the solution. A breakdown (p·Ap ≤ eps·|r·z|) stops the iteration silently, as before.

Aeolus.PressureSolvers.solve! — Method
solve!(p, source, solver::MultigridPoissonSolver)

AbstractPressureSolver interface: solve ∇²p = source in place. Drop-in replacement for the FFT and CG solvers.
