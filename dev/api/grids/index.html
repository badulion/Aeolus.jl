Grids

The Aeolus.Grids module defines the mesh types and coordinate access. See Staggered discretization for the physical meaning of the Location types and Architecture for how AbstractMesh fits into the extensibility story.

Mesh types

Aeolus.Grids.AbstractMesh — Type
AbstractMesh{T <: AbstractFloat}

Root of the mesh type hierarchy. T is the element type of the coordinate data (typically Float64). Every concrete subtype must implement:

  • totalsize(mesh) — tuple of storage-array dimensions (halos included).
  • interior(mesh) — tuple of interior index ranges (iᵢ, iⱼ, iₖ).
  • xnodes(mesh, ::Location), ynodes(mesh, ::Location), znodes(mesh, ::Location) — physical coordinate vectors at the given Location.

Concrete subtypes: RegularGrid. Planned: SpectralElementMesh.

Aeolus.Grids.RegularGrid — Type
RegularGrid{T}(; size, extent, halo=(2,2,2), origin=(0,0,0))

Uniform 3D Cartesian mesh (finite-volume backend) with a halo region on each side.

size = (Nx, Ny, Nz) number of interior cells per dimension. extent = (Lx, Ly, Lz) physical domain size. halo = (Hx, Hy, Hz) halo width per dimension (>= 1).

Storage arrays have shape (Nx+2Hx, Ny+2Hy, Nz+2Hz). Interior indices are Hx+1 : Hx+Nx, etc.

Location tags

Aeolus.Grids.Location — Type
Location

Abstract tag type identifying where a scalar field's samples sit on a staggered mesh. On the Arakawa-C grid used by RegularGrid:

  • CellCenter — cell interior; used for pressure, θ, tracers.
  • FaceX — west face of each cell; used for u.
  • FaceY — south face of each cell; used for v.
  • FaceZ — bottom face of each cell; used for w.

Finite-volume operator kernels dispatch on (::Location, ::Location, …) so that e.g. ∂x(FaceX → CellCenter) (divergence) picks a different stencil from ∂x(CellCenter → FaceX) (gradient).

Aeolus.Grids.CellCenter — Type

Cell-center location. See Location.

Aeolus.Grids.FaceX — Type

West-face location — the u-velocity live here. See Location.

Aeolus.Grids.FaceY — Type

South-face location — the v-velocity lives here. See Location.

Aeolus.Grids.FaceZ — Type

Bottom-face location — the w-velocity lives here. See Location.

Coordinate access

Aeolus.Grids.xnodes — Function
xnodes(mesh, location)
ynodes(mesh, location)
znodes(mesh, location)

Physical coordinates of a field at the given location, one entry per interior sample. Length matches the interior extent along that axis (Nx, Ny, or Nz for a RegularGrid). Face locations return the coordinate of the west / south / bottom face of each cell; the opposite face wraps periodically and is not stored separately.

Aeolus.Grids.interior — Function
interior(mesh) -> (irange, jrange, krange)

Index ranges that walk the interior (halo-excluded) portion of a field's backing array on mesh. Used everywhere kernels loop over data.

Aeolus.Grids.totalsize — Function
totalsize(mesh)

Tuple of the storage-array dimensions for a scalar field on mesh, including the halo cells on every side.
