Aerosol optics (Phase 37)

Aeolus.AerosolOptics.KELVIN_A_298 — Constant

Kelvin coefficient A = 2σM/(RTρ) in μm at 298.15 K (≈ 1.05 × 10⁻³ μm).

Derived from MoistThermodynamics.kelvin_coefficient, the package's single definition, rather than from a local surface tension. The local constant previously used σ = 0.0728 N/m — the 20 °C value — at 298.15 K, where the measured value is 0.0720. That is only 0.8 % in A, but s_crit ∝ A^{3/2}, so it became 1.2 % in critical supersaturation, and it put this module and the Köhler contract into quiet disagreement about whether a given particle activates.

Aeolus.AerosolOptics.AerosolBandOptics — Type
AerosolBandOptics{T}

Band-mean bulk aerosol optical properties for one population at one humidity.

  • λ — representative wavelength per band, μm
  • β_ext — extinction coefficient per band, m⁻¹
  • ssa — single-scattering albedo per band
  • g — asymmetry parameter per band
  • β_550 — monochromatic extinction at 550 nm, m⁻¹ (the AOD reference)
  • rh — the relative humidity these were computed at
Aeolus.AerosolOptics.AerosolMode — Type
AerosolMode

Abstract supertype for one mode of an aerosol size distribution. A complete aerosol population is a Vector{<:AerosolMode} — the standard representation, because ambient aerosol is essentially never unimodal (nucleation, accumulation and coarse modes have different sources, sinks and chemistry).

Aeolus.AerosolOptics.AerosolProfile — Type
AerosolProfile{T} <: AbstractAerosolOptics

A vertically resolved aerosol population on a radiation column.

  • modes — the reference mixture (number concentrations as given)
  • scale — per-layer multiplier on those number concentrations
  • rh — per-layer relative humidity, [0,1]
  • dz — layer thickness, m
  • z — layer-centre height, m
  • table — the humidity-interpolated band-optics table
  • τ, ssa, g — per-layer, per-band optical properties, already multiplied by scale·dz so τ[k,b] is the layer optical depth

The profile is a AbstractAerosolOptics, so it plugs into the radiation compute_optics! contract and merges with gas and cloud optics.

Vertical shape: an exponentially decaying boundary-layer term plus an optional elevated layer (a Saharan air layer, a biomass-burning plume or a volcanic/stratospheric sheet), the whole normalised to a prescribed 550 nm aerosol optical depth. Prescribing AOD rather than mass is the operational convention because AOD is what is actually measured — by sun photometers on the ground and by satellite from space.

Aeolus.AerosolOptics.AerosolSpecies — Type
AerosolSpecies

A chemical aerosol component: a tabulated complex refractive index m(λ) = n(λ) + i k(λ), a material density and a κ hygroscopicity.

  • name — identifying symbol
  • λ — wavelength table, μm, strictly increasing
  • n, k— real and imaginary parts at those wavelengths (k ≥ 0)
  • ρ — material density, g cm⁻³
  • κ — Petters-Kreidenweis hygroscopicity parameter
  • source— literature provenance of the optical constants

The imaginary part spans ~8 decades across the species set (10⁻⁸ for sulphate in the visible, 0.44 for soot), so k is interpolated logarithmically; n varies by tens of percent and is interpolated linearly. Both are interpolated against log λ and clamped outside the table rather than extrapolated — extrapolating a resonance band is a good way to invent absorption that does not exist.

Aeolus.AerosolOptics.HygroscopicTable — Type
HygroscopicTable{T}

Band optics of one aerosol mixture tabulated on a humidity grid, so that a column with a different RH in every layer costs one interpolation per layer instead of one Mie integration per layer.

Fields rh (nodes), u = -ln(1-rh), β_ext, ssa, g (n_rh × n_band matrices), β_550 (per node), and λ (per band).

If every mode of the mixture is hydrophobic (κ < 10⁻⁶ — pure soot or pure dust) the table collapses to a single node, because there is nothing to interpolate.

Aeolus.AerosolOptics.LogNormalMode — Type
LogNormalMode{T} <: AerosolMode

One log-normal mode:

\[\frac{dN}{d\ln r} = \frac{N}{\sqrt{2π}\,\ln σ_g} \exp\!\left[-\frac{\ln^2(r/r_g)}{2\ln^2σ_g}\right]\]

  • species — the chemical component
  • N — total number concentration, cm⁻³
  • r_g — geometric median dry radius, μm
  • σ_g — geometric standard deviation (dimensionless, > 1)

The log-normal is not a convenience: coagulation and condensation drive a size distribution towards self-preserving log-normal shape, which is why measured aerosol spectra are described by two or three of them.

Moments are analytic, ⟨r^p⟩ = r_g^p \exp(p^2\ln^2σ_g/2), and grow explosively with p: for σ_g = 2 the sixth moment (which controls Rayleigh scattering) is 5700 r_g^6. This is why the quadrature range in mode_optics is extended on the coarse side.

Aeolus.AerosolOptics.MieResult — Type
MieResult{T}

Efficiency factors and the first phase-function moment for a single homogeneous sphere:

  • Q_ext — extinction efficiency, C_ext / πr²
  • Q_sca — scattering efficiency
  • Q_abs — absorption efficiency, Q_ext - Q_sca (≥ 0)
  • Q_back — backscattering efficiency (lidar-relevant)
  • g — asymmetry parameter ⟨cos Θ⟩ ∈ [-1, 1]
  • nterms — number of terms retained in the Mie series

The efficiencies are per geometric cross-section, so Q_ext → 2 as x → ∞ (the extinction paradox: a large sphere removes twice the light its shadow accounts for, half by absorption/reflection and half by near-forward diffraction).

Aeolus.AerosolOptics._quadrature_points — Method
_quadrature_points(r_lo, r_hi, λ, nquad) -> Int

Number of Simpson intervals for one mode. nquad is a floor: for coarse modes the interference ("ripple") structure of Q_ext(x) has a period of roughly Δx = π, so resolving it needs about POINTS_PER_RIPPLE·(x_hi - x_lo)/π points. A fixed 120 intervals is ample for an accumulation mode (x < 40) but under-resolves a 20 μm sea-salt or dust particle at 0.4 μm (x > 300), where it leaves a ~0.3 % ripple-aliasing error in β_ext. Capped at NQUAD_CEILING_FACTOR·nquad so the cost stays bounded in the ultraviolet bands.

Aeolus.AerosolOptics.aerosol_band_optics — Method
aerosol_band_optics(modes, spec; rh = 0.0, nsub = 2, nquad = 120)
    -> AerosolBandOptics

Integrate the mixture's Mie optics onto the bands of spec. Each band is sampled at nsub wavelengths equally spaced in wavenumber and the results averaged — nsub = 1 (band centre) is noticeably biased for the widest shortwave bands, where β_ext varies by tens of percent across the band because of the λ^{-α} Ångström dependence.

Averaging is done on the coefficients, i.e. β_ext and β_sca are averaged and ω₀, g recomputed from them, rather than averaging ω₀ and g directly. This is the same weighting combine_optics! uses and keeps the band mean energetically consistent.

Aeolus.AerosolOptics.aerosol_extinction_profile — Method
aerosol_extinction_profile(profile; band = nothing) -> Vector

Per-layer extinction coefficient in m⁻¹, at 550 nm by default or in the given band.

Aeolus.AerosolOptics.aerosol_heating_rate — Method
aerosol_heating_rate(profile, col; μ₀ = 0.5, sfc_albedo = 0.05,
                     kwargs...) -> Vector

Per-layer shortwave heating rate difference caused by the aerosol, K day⁻¹. A black-carbon plume produces a sharply peaked positive anomaly at its own altitude — this is the direct-effect analogue of the "semi-direct" cloud response, and the vertical structure is what determines whether the plume stabilises or destabilises the layer below.

Aeolus.AerosolOptics.aerosol_mixture — Method
aerosol_mixture(name::Symbol; scale = 1.0) -> Vector{LogNormalMode}

Look up one of the standard mixtures by name (see AEROSOL_MIXTURE_NAMES) and optionally multiply every number concentration by scale. Because Mie optics are linear in number concentration, scale rescales β_ext exactly and leaves ω₀ and g untouched.

aerosol_optical_depth(profile, band) -> τ

Aeolus.AerosolOptics.aerosol_optical_depth — Method
aerosol_optical_depth(profile) -> Vector

Aeolus.AerosolOptics.aerosol_optical_depth_550 — Method
aerosol_optical_depth_550(profile) -> τ₅₅₀

Aeolus.AerosolOptics.aerosol_profile — Method
aerosol_profile(mixture, nz, z; aod_550 = 0.2, scale_height = 2000.0,
                rh = 0.0, spec = shortwave_bands(),
                elevated_layer = nothing, elevated_fraction = 0.0,
                dz = nothing, nsub = 2, nquad = 120) -> AerosolProfile

Build a column aerosol profile.

  • mixture — a Vector{<:AerosolMode} (e.g. urban()) or a symbol accepted by aerosol_mixture
  • nz — number of layers
  • z — layer-centre heights (m), a vector of length nz, or a scalar domain top for a uniform grid
  • aod_550 — target column optical depth at 550 nm; the vertical shape is rescaled so the integral matches this exactly
  • scale_height — e-folding depth H of the boundary-layer term, f(z) = exp(-z/H); 1-2 km is typical for a well-mixed continental boundary layer, 0.5-1 km for marine
  • elevated_layer — (z_bottom, z_top) in m for an additional uniform slab, carrying elevated_fraction of the total 550 nm AOD
  • rh — scalar or per-layer relative humidity; pass relative_humidity_profile(col) to drive it from the thermodynamic state

The exponential shape is the observed one: aerosol is emitted at the surface and removed by wet deposition, and turbulent mixing against that gives a near-exponential decay with a scale height close to the boundary-layer depth. The elevated-layer option exists because the two optically most important aerosol features on Earth — the Saharan air layer and stratospheric volcanic sulphate — are not surface-attached, and their radiative effect (especially over cloud) depends on being placed correctly in the vertical.

Aeolus.AerosolOptics.aerosol_radiative_forcing — Method
aerosol_radiative_forcing(profile, col; μ₀ = 0.5, sfc_albedo = 0.05,
                          gas = nothing, rayleigh = true,
                          solver = nothing)
    -> (toa, surface, atmosphere, ...)

Shortwave direct aerosol radiative effect: the difference in net flux between an atmosphere with the aerosol and the same atmosphere without it, solved twice with the Phase 33 two-stream solver.

Returns a NamedTuple

  • toa — ΔF_net at the model top, W m⁻². Negative = the planet loses energy = cooling.
  • surface — ΔF_net at the surface, W m⁻². Negative = dimming.
  • atmosphere — toa - surface, the change in energy absorbed within the column. Positive = the aerosol layer heats.
  • net_toa_clean, net_toa_aerosol, net_sfc_clean, net_sfc_aerosol — the four raw fluxes, for diagnosis
  • aod_550 — the column 550 nm optical depth, for normalisation
  • forcing_efficiency — toa / aod_550, W m⁻² per unit AOD, the quantity usually quoted for intercomparison

The identity ΔF_atm = ΔF_toa - ΔF_sfc is exact by construction and is the cleanest way to separate the two aerosol effects that a single TOA number conflates:

  • a scattering aerosol (sulphate, sea salt) over a dark surface reflects sunlight back to space: ΔF_toa < 0, ΔF_sfc < 0, ΔF_atm ≈ 0. It cools the planet and the surface and does nothing to the atmosphere.
  • an absorbing aerosol (black carbon) also dims the surface strongly, but the energy it removes from the beam stays in the column: ΔF_atm > 0. The TOA sign then depends on the surface albedo — see critical_surface_albedo.

gas may be a concrete AbstractGasOptics (Phase 32); if it is nothing the clean atmosphere is molecular-scattering only (rayleigh = true) or completely transparent (rayleigh = false). The comparison is differential, so the choice mostly affects the magnitude, not the sign — but Rayleigh scattering matters for the critical albedo because it provides a floor of atmospheric backscatter.

Aeolus.AerosolOptics.angstrom_exponent — Method

Monochromatic form: the Ångström exponent of a mixture between two wavelengths in μm (the AERONET reference pair is 440/870 nm).

Aeolus.AerosolOptics.angstrom_exponent — Method
angstrom_exponent(optics::AerosolBandOptics, b1, b2) -> α

Ångström wavelength exponent between two bands,

\[α = -\frac{\ln(β_{ext}(λ_1)/β_{ext}(λ_2))}{\ln(λ_1/λ_2)}\]

so that β_ext ∝ λ^{-α} (Ångström 1929).

α is the classical remote-sensing discriminator of particle size, because it measures how far the particles are from the two limits:

  • α → 4 — Rayleigh (molecules, x ≪ 1)
  • α ≈ 1.5–2.5 — fine/accumulation mode: urban pollution, biomass smoke, secondary sulphate
  • α ≈ 0.5–1.2 — mixed continental
  • α ≈ 0–0.5 — coarse mode: desert dust, sea salt; α → 0 is the geometric-optics limit where Q_ext → 2 independent of wavelength

A negative α is possible for a very coarse population and is not an error.

Aeolus.AerosolOptics.angstrom_exponent — Method
angstrom_exponent(profile, band1, band2) -> α

Ångström exponent of a column profile, from the column optical depths in the two bands. Identical to the coefficient form when the humidity is uniform; when it is not, this is the correctly AOD-weighted column value, which is what a sun photometer retrieves.

Aeolus.AerosolOptics.antarctic — Method
antarctic() -> Vector{LogNormalMode}

Antarctic background: a sulphate droplet mode, a trace of sea salt and a trace of transported mineral dust. The cleanest tropospheric aerosol on the planet — total number ~43 cm⁻³, three to four orders of magnitude below urban.

Aeolus.AerosolOptics.bulk_optics — Method
bulk_optics(modes, λ; rh = 0.0, T_K = 298.15, nquad = 120)
    -> (β_ext, β_sca, β_abs, ssa, g)

External mixture of the modes: extinction and scattering coefficients (m⁻¹) add, the single-scattering albedo is β_sca/β_ext, and the asymmetry parameter is weighted by scattering coefficient. rh may be a scalar (applied to every mode) — each mode grows according to its own species' κ.

"External mixture" means every mode is its own particle population; the alternative (internal mixing, where soot is a core inside a sulphate shell) raises BC absorption by a factor 1.5-2 and is a well-known structural uncertainty in aerosol forcing. This implementation is external, which is the OPAC convention.

Aeolus.AerosolOptics.critical_surface_albedo — Method
critical_surface_albedo(profile, col; μ₀ = 0.5, tol = 1e-4, kwargs...)
    -> α_c

Surface albedo at which the TOA shortwave aerosol forcing changes sign.

For an aerosol with single-scattering albedo ω₀ and upscatter fraction β, the single-scattering TOA forcing is (Chylek & Coakley 1974; Haywood & Shine 1995)

\[ΔF_{TOA} \propto (1-α_s)^2\,2β\,ω_0 - 4α_s(1-ω_0)\]

which vanishes at a critical albedo α_c. Below α_c the surface is dark, the aerosol's backscatter dominates and the aerosol cools; above α_c the surface already returns most of the sunlight, the aerosol's absorption dominates, and the same aerosol warms. This is why black carbon deposited over snow, ice or bright cloud is so much more potent than the same soot over ocean.

This function finds α_c numerically from the full multiple-scattering solution rather than from the single-scattering formula, by bisecting aerosol_radiative_forcing.toa on α ∈ [0, 0.99]. Returns NaN if the forcing has the same sign at both ends — which is the correct answer for a purely scattering aerosol, whose TOA forcing is negative at every albedo below 1.

Aeolus.AerosolOptics.desert — Method
desert() -> Vector{LogNormalMode}

Desert dust: the three OPAC mineral modes (nucleation 0.07 μm, accumulation 0.39 μm, coarse 1.9 μm) with a modest water-soluble background. Coarse-mode dominated, so α ≈ 0.1-0.3, and the only mixture here with a first-order longwave effect.

Aeolus.AerosolOptics.growth_factor — Method
growth_factor(r_dry, rh, κ; T_K = 298.15) -> r_wet / r_dry

Hygroscopic growth factor. In the large-particle limit the Kelvin term is negligible and the κ-Köhler relation inverts analytically to

\[GF = \left(1 + κ\frac{RH}{1-RH}\right)^{1/3}\]

so GF diverges as (1-RH)^{-1/3} at saturation. The (1-RH)^{-1} inside the cube root is the reason aerosol extinction explodes in the last few percent of humidity and is the dominant control on visibility in haze.

Measured values from this implementation at r_dry = 0.1 μm: sea salt (κ = 1.10) grows by ×2.19 at RH = 90 % and ×4.47 at RH = 99 %; sulphate (κ = 0.60) by ×1.83 and ×3.61; ammonium nitrate (κ = 0.67) by ×1.89 and ×3.75; organic carbon (κ = 0.10) by ×1.22 and ×1.95; mineral dust (κ = 0.03) by ×1.08 and ×1.39; black carbon (κ = 0) not at all.

Aeolus.AerosolOptics.hygroscopic_table — Method

Aeolus.AerosolOptics.interpolate_rh — Method
interpolate_rh(tab, rh) -> (β_ext::Vector, ssa::Vector, g::Vector, β_550)

Band optics at an arbitrary relative humidity, by linear interpolation in u = -ln(1-RH) (logarithmic for β_ext, linear for ssa and g). Humidities above the top node are clamped, not extrapolated: beyond RH ≈ 0.995 the growth is limited by kinetics and by the finite water supply, not by equilibrium thermodynamics, so extrapolating the equilibrium curve would be actively wrong.

Aeolus.AerosolOptics.kohler_saturation — Method
kohler_saturation(r_wet, r_dry, κ; T_K = 298.15) -> S

Equilibrium water-vapour saturation ratio over a solution droplet of wet radius r_wet grown from a dry radius r_dry (both μm), in the single-parameter (κ-Köhler) representation of Petters & Kreidenweis (2007):

\[S(r_w) = \frac{r_w^3 - r_d^3}{r_w^3 - r_d^3(1-κ)}\; \exp\!\left(\frac{A}{r_w}\right)\]

The first factor is the solute (Raoult) term — κ is the volume of water taken up per unit volume of dry solute at unit water activity — and the exponential is the Kelvin curvature term.

Aeolus.AerosolOptics.mie_sphere — Method
mie_sphere(x, m; nmax = 0) -> MieResult

Mie solution for a homogeneous sphere of size parameter x = 2πr/λ and complex refractive index m = n + ik, k ≥ 0 for an absorbing material (the Bohren-Huffman exp(-iωt) convention).

The series coefficients are

\[a_n = \frac{[D_n(mx)/m + n/x]\,ψ_n(x) - ψ_{n-1}(x)} {[D_n(mx)/m + n/x]\,ξ_n(x) - ξ_{n-1}(x)},\qquad b_n = \frac{[m D_n(mx) + n/x]\,ψ_n(x) - ψ_{n-1}(x)} {[m D_n(mx) + n/x]\,ξ_n(x) - ξ_{n-1}(x)}\]

with D_n(z) = ψ'_n(z)/ψ_n(z) the logarithmic derivative, ψ_n = z j_n, ξ_n = ψ_n - iχ_n, χ_n = -z y_n the Riccati-Bessel functions. From these

\[Q_{ext} = \frac{2}{x^2}\sum_n (2n+1)\,\mathrm{Re}(a_n + b_n),\qquad Q_{sca} = \frac{2}{x^2}\sum_n (2n+1)(|a_n|^2 + |b_n|^2)\]

\[g\,Q_{sca} = \frac{4}{x^2}\left[ \sum_n \frac{n(n+2)}{n+1}\mathrm{Re}(a_n a_{n+1}^* + b_n b_{n+1}^*) + \sum_n \frac{2n+1}{n(n+1)}\mathrm{Re}(a_n b_n^*)\right]\]

D_n is obtained by downward recursion D_{n-1} = n/z - 1/(D_n + n/z) seeded at order N_mx = max(N_stop, |mx|) + 15 with D_{N_mx} = 0. The upward form of the same recursion is numerically unstable — for |mx| ≳ 10 it loses every significant digit within a few tens of terms, which produces plausible-looking but completely wrong absorption. This is the single most important numerical point in a Mie code (Wiscombe 1980, §2).

Truncation order N_stop = ⌈x + 4x^{1/3} + 2⌉ (Wiscombe 1980 Eq. 20); pass nmax to override.

Aeolus.AerosolOptics.mode_optics — Method
mode_optics(mode, λ; rh = 0.0, T_K = 298.15, nquad = 120)
    -> (β_ext, β_sca, β_abs, g)

Bulk optical coefficients of a single log-normal mode at wavelength λ (μm) and relative humidity rh, per unit number concentration (i.e. for N = 1 cm⁻³), in m⁻¹:

\[β_{ext} = \int_0^∞ π r_w^2\,Q_{ext}(x_w, m_w)\,\frac{dN}{d\ln r_d}\,d\ln r_d\]

with, at each dry radius r_d, the wet radius r_w from wet_radius, the volume-mixed refractive index m_w from wet_refractive_index and x_w = 2πr_w/λ. Note the integral is over the dry distribution: growth conserves particle number, so each dry particle maps to exactly one wet particle.

The asymmetry parameter returned is the scattering-weighted mean, g = ∫ πr²Q_sca g dN / ∫ πr²Q_sca dN, which is the only weighting that makes combine_optics! associative.

Quadrature

Composite Simpson in ln r over [r_g e^{-4\lnσ_g},\; r_g e^{+4\lnσ_g + 3\ln^2σ_g}], clipped to [1 nm, 20 μm]. The asymmetric upper limit tracks the mode of the r³-weighted integrand (\ln r_g + 3\ln^2σ_g), which for σ_g = 2.5 sits 2.7 σ above the number median — a symmetric range would truncate the very particles that dominate extinction.

nquad is a floor on the number of Simpson intervals; the actual count is raised for coarse modes by _quadrature_points so that the Mie ripple is resolved. Measured convergence of β_ext(550 nm) against a 7680-interval reference: better than 0.15 % for every library mixture at the default nquad = 120 (6 × 10⁻⁵ for the fine-mode-dominated ones; the residual is ripple aliasing in the 20 μm sea-salt and dust tails).

Aeolus.AerosolOptics.rayleigh_efficiencies — Method
rayleigh_efficiencies(x, m) -> MieResult

Analytic small-particle (Rayleigh) limit of the Mie solution, with μ = (m² - 1)/(m² + 2) the Clausius-Mossotti factor:

\[Q_{sca} = \tfrac{8}{3}x^4|μ|^2, \qquad Q_{abs} = 4x\,\mathrm{Im}(μ), \qquad g = O(x^2) \approx 0\]

Used by mie_sphere for x < 10⁻³, where the upward Riccati-Bessel recursion ψ_n = (2n-1)ψ_{n-1}/x - ψ_{n-2} loses all significant digits to cancellation (ψ₁ ≈ x²/3 is formed as a difference of two numbers of order 1). The relative error of the truncation is O(x²) ≲ 10⁻⁶ at the switch-over, verified in the test suite by continuity across x = 10⁻³.

Aeolus.AerosolOptics.wet_radius — Method
wet_radius(r_dry, rh, κ; T_K = 298.15) -> r_wet

Equilibrium wet radius (μm) of a dry particle of radius r_dry (μm) at relative humidity rh ∈ [0,1), by inverting kohler_saturation.

For sub-saturated air the Köhler curve S(r_w) rises monotonically from 0 at r_w = r_d to the critical supersaturation S_c > 1 and then decays back towards 1 from above, so S(r_w) = RH < 1 has exactly one root and it lies on the stable (lower) branch. Bisection is therefore globally convergent and needs no branch selection.

Hydrophobic species (κ ≈ 0) return r_dry unchanged: with no solute the only term left is the Kelvin factor, which is > 1 for every radius, so no sub-saturated equilibrium exists — physically, a soot particle does not take up water.

Deliquescence/efflorescence hysteresis is not represented: κ-Köhler gives the metastable, continuously-deliquesced branch. That is the appropriate choice for aged ambient aerosol (which has usually been above its deliquescence point at some time in its history), but it will overestimate uptake for freshly crystalline salt between the efflorescence and deliquescence humidities.

Aeolus.AerosolOptics.wet_refractive_index — Method
wet_refractive_index(m_dry, r_dry, r_wet) -> ComplexF64

Refractive index of a grown particle by volume mixing of the dry material and the condensed water:

\[m_{wet} = f\,m_{dry} + (1-f)\,m_{water},\qquad f = (r_d/r_w)^3\]

Volume mixing is the rule used by OPAC and by most GCM aerosol schemes. It is exact in neither limit — a Maxwell-Garnett or Bruggeman effective medium is formally better for an inclusion-in-matrix morphology — but for a genuinely dissolved solute (which is what a deliquesced sulphate or sea-salt droplet is) volume mixing of the solution refractive index is the physically correct construction, and the differences are a few percent in ω₀.

Aeolus.RadiationCore.compute_optics! — Method
compute_optics!(optics, aerosol::AerosolProfile, col, spec; add = true)

Radiation optics contract for aerosol. Writes the profile's layer optical depth, single-scattering albedo and asymmetry parameter into optics for every g-point.

With add = true (the default) the aerosol is merged into whatever optics already holds, using exactly the algebra of RadiationCore.combine_optics!:

\[τ = τ_g + τ_a,\qquad ω = \frac{τ_gω_g + τ_aω_a}{τ},\qquad g = \frac{τ_gω_g g_g + τ_aω_a g_a}{τ_gω_g + τ_aω_a}\]

so the usual call sequence is

compute_optics!(o, gas_optics, col)          # fills
compute_optics!(o, cloud_optics_buffer, col) # fills a second buffer
combine_optics!(o, cloud_buffer)
compute_optics!(o, aerosol_profile, col)     # merges in place

Pass add = false to overwrite instead (the behaviour of the gas and cloud methods), which is what you want when filling a dedicated aerosol buffer for a later combine_optics!.

Within a band all g-points get the same aerosol properties: aerosol extinction varies smoothly across a band, so it carries no correlated-k structure of its own. That is the standard treatment (RRTMGP does the same) and it is why the aerosol table is per band rather than per g-point.
