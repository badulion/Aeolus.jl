Shared contract — RadiationCore

RadiationCore fixes the interface every radiation component speaks: the spectral grid and its g-points, the $\tau$/$\omega$/$g$ optical-property triple with its correct combination rule, level-based radiative fluxes, and the abstract solver interfaces.

Aeolus.RadiationCore.AbstractAerosolOptics — Type
AbstractAerosolOptics

Aerosol optical properties from the aerosol state. Same contract. Phase 37.

Aeolus.RadiationCore.AbstractCloudOptics — Type
AbstractCloudOptics

Cloud optical properties from the condensate state (ql, qi, effective radii). Implements the same compute_optics! contract. Phase 33.

Aeolus.RadiationCore.AbstractGasOptics — Type
AbstractGasOptics

Gas optical properties from the thermodynamic and composition state. Concrete types implement

compute_optics!(optics, gasopt, column)

filling optics.τ, .ssa, .g for every layer and g-point. Phase 32 supplies the correlated-k implementation.

Aeolus.RadiationCore.AbstractRTSolver — Type
AbstractRTSolver

Radiative-transfer solver. Concrete types implement

solve_rt!(fluxes, solver, optics, column, surface; μ₀, ...)

Phase 33 supplies two-stream; Phase 34 supplies 3-D Monte Carlo; Phase 35 supplies urban radiosity.

Aeolus.RadiationCore.AbstractSurfaceOptics — Type
AbstractSurfaceOptics

Surface reflection and emission. Concrete types implement surface_albedo(s, band, μ₀, ...) and surface_emissivity(s, band). Phase 36 supplies the spectral/BRDF implementation.

Aeolus.RadiationCore.AtmosphericColumn — Type
AtmosphericColumn{T}

The thermodynamic and composition state a radiation scheme needs, on a single column, all bottom-up.

Layer quantities (Nz): p_lay (Pa), T_lay (K), dz (m), ρ (kg m⁻³), vmr (a Dict{Symbol,Vector{T}} of volume mixing ratios by gas), ql, qi (kg kg⁻¹ condensate), r_eff_liq, r_eff_ice (μm).

Level quantities (Nz+1): p_lev (Pa), T_lev (K).

Surface: T_sfc (K).

vmr keys are gas symbols — :h2o, :co2, :o3, :ch4, :n2o, :o2, :n2. A gas-optics implementation documents which it requires.

Aeolus.RadiationCore.OpticalProperties — Type
OpticalProperties{T}

Layer optical properties on a column or a 3-D field, per g-point.

  • τ — optical depth (dimensionless, ≥ 0)
  • ssa — single-scattering albedo ω₀ ∈ [0,1]
  • g — asymmetry parameter ∈ [-1,1]

Array shape is (dims..., ngpt) where dims is (Nz,) for a single column or (Nx, Ny, Nz) for a 3-D field. Layer index runs bottom-up.

A purely absorbing medium has ssa = 0; conservative scattering has ssa = 1. For the two-stream solver g is the first moment of the phase function (0 isotropic, ~0.85 typical for cloud droplets).

Aeolus.RadiationCore.RadiativeFluxes — Type
RadiativeFluxes{T}

Broadband fluxes at layer interfaces (levels), shape (dims..., Nz+1) with level 1 the surface and level Nz+1 the model top, all positive magnitudes:

  • flux_up — upward flux
  • flux_dn — total downward flux (direct + diffuse)
  • flux_dn_dir — direct-beam downward flux (shortwave only; zero in LW)
  • flux_net — flux_dn - flux_up, positive downward

Fluxes are broadband (already summed over g-points with their weights) because that is what the thermodynamics needs. A solver that wants per-band output should keep its own spectral array and reduce into this.

Aeolus.RadiationCore.SpectralGrid — Type
SpectralGrid{T}

Correlated-k spectral discretisation. nband contiguous wavenumber bands, each subdivided into g-points. Fields:

  • band_lo, band_hi — band limits in cm⁻¹, length nband
  • gpt_per_band — g-points in each band, length nband
  • gpt_band — band index of each g-point, length ngpt
  • gpt_weight — quadrature weight of each g-point; within a band the weights sum to 1, so a band-integrated quantity is Σ_g w_g · x_g over that band's g-points
  • solar_src — top-of-atmosphere solar irradiance per g-point (W m⁻², sums to SOLAR_CONSTANT for a shortwave grid; all zeros for a longwave grid)
  • kind — :shortwave or :longwave

The g-point weights are what make a correlated-k scheme a quadrature rather than a band average: within a band the absorption coefficient is reordered monotonically and integrated in cumulative-probability space, so a handful of g-points reproduces the line-by-line band transmission.

Aeolus.RadiationCore._gauss_legendre — Method
_gauss_legendre(n) -> (x, w)

n-point Gauss-Legendre nodes and weights on [-1, 1] (Newton iteration on the Legendre polynomial $P_n$). Orders up to 64 come from a table filled when the module loads; higher orders are memoised under a lock, so the function is safe to call from any thread. The returned vectors are shared: do not modify them.

Aeolus.RadiationCore.allocate_column_optics — Method
allocate_column_optics(T, nlay, ncol, spec) -> OpticalProperties{T,3}

Zeroed optical properties of ncol independent columns of nlay layers, in the layout of the multi-column radiation solves (KA-n, #305): τ[k, g, c] for layer k, g-point g, column c. Column c is laid out exactly as a single column's allocate_optics(T, (nlay,), spec).

Aeolus.RadiationCore.allocate_fluxes — Method
allocate_fluxes(T, dims, nlev) -> RadiativeFluxes

Allocate zeroed fluxes for horizontal shape dims (a possibly-empty tuple) and nlev levels.

Aeolus.RadiationCore.allocate_optics — Method
allocate_optics(T, dims, spec) -> OpticalProperties

Allocate zeroed optical properties for layer shape dims (a tuple) and spectral grid spec. The trailing dimension is ngpoints(spec).

Aeolus.RadiationCore.band_wavelength — Method
band_wavelength(spec, b; sub = 1, nsub = 1) -> λ in μm

Wavelength of a band, or of one of nsub equal-wavenumber sub-intervals within it. With the defaults this is the wavelength of the band's wavenumber midpoint.

The sub-interval form exists for optical-property models that need to integrate a strongly wavelength-dependent quantity across a band — Mie efficiencies ripple on a scale far finer than an RRTMG band, so evaluating them once at the band centre is not good enough.

This lives in RadiationCore rather than in any one optics module because four separate copies of it had appeared by the end of the radiation work (in SurfaceOptics, AerosolOptics, TwoStream and, in spirit, SolarGeometry). It is a property of the spectral grid, so it belongs with the spectral grid.

See also SurfaceOptics.band_center_wavelength, which is a different quantity: the Planck-weighted mean wavelength over the band. That one needs a source temperature and stays where the weighting machinery is.

Aeolus.RadiationCore.band_wavelength_limits — Method
band_wavelength_limits(spec, b) -> (λ_lo, λ_hi)

Wavelength limits of band b in μm. Bands are stored in wavenumber (cm⁻¹), which is the natural coordinate for the transfer equation because it is linear in energy; wavelength is what optical-property tables are almost always keyed on. Note the order reverses — the high-wavenumber edge is the short-wavelength one.

Aeolus.RadiationCore.column_from_profiles — Method
column_from_profiles(θ, dz; p_surf = 101325, qv = nothing, ql = nothing,
                     qi = nothing, vmr = nothing, T_sfc = nothing,
                     r_eff_liq = 10, r_eff_ice = 30) -> AtmosphericColumn

A radiation column from layer profiles of potential temperature θ (K, reference pressure 1000 hPa) on layers of thickness dz (m), bottom-up. Pressure is integrated hydrostatically from p_surf with the dry-air density of each layer, T = θ·(p/p₀)^{R_d/c_p} at the layer mid-point; levels get the mean of the adjacent layer temperatures (the bottom and top level the temperature of their layer).

qv (specific humidity, kg/kg) becomes the :h2o volume mixing ratio qv·M_air/M_h2o; the other gases come from vmr or a standard mid-latitude composition. ql, qi (kg/kg) are the condensate the cloud optics reads, with effective radii r_eff_liq, r_eff_ice (μm, scalars or per-layer). T_sfc defaults to the lowest layer's temperature.

This is the hydrostatic core of column_from_simulation, for a caller that has already reduced the LES to a profile (a domain mean, a masked mean over the fluid cells).

Aeolus.RadiationCore.column_from_simulation — Method
column_from_simulation(sim, i, j; kwargs...) -> AtmosphericColumn

Extract a radiation column from a running BoussinesqSimulation at horizontal index (i, j). Because the Boussinesq system carries no pressure or density profile, a hydrostatic reference must be supplied: pass p_surf and use the simulation's θ to build T. Gas mixing ratios default to a standard mid-latitude composition; override via vmr.

This is a convenience for coupling the radiation stack to the LES; for the anelastic core the ReferenceState already carries p̄ and ρ̄ and should be used instead.

Aeolus.RadiationCore.combine_optics! — Method
combine_optics!(dst, src)

Add the optical properties of src into dst, correctly combining the scattering moments. Optical depths add, but ssa and g are weighted averages — ssa by optical depth, g by scattering optical depth:

\[τ = τ_1 + τ_2, \qquad ω = \frac{τ_1ω_1 + τ_2ω_2}{τ}, \qquad g = \frac{τ_1ω_1g_1 + τ_2ω_2g_2}{τ_1ω_1 + τ_2ω_2}\]

Getting this wrong (e.g. averaging g by optical depth) is a classic and silent source of error when combining gas, cloud and aerosol optics.

Aeolus.RadiationCore.flux_divergence! — Method
flux_divergence!(div, f, dz) -> div

Layer flux divergence ∂F_net/∂z from level fluxes, in W m⁻³. div has the layer shape (one fewer element in the last dimension than f). dz may be a scalar or a per-layer vector.

Sign: a negative divergence of the downward-positive net flux means the layer is absorbing energy, hence warming. heating_rate! applies that sign convention.

Aeolus.RadiationCore.gpoint_range — Method

Index range of the g-points belonging to band b.

Aeolus.RadiationCore.heating_rate! — Method
heating_rate!(dθdt, f, dz, ρ; cp = 1004.6) -> dθdt

Radiative heating rate in K s⁻¹ from the net-flux divergence:

\[\left(\frac{∂θ}{∂t}\right)_{rad} = \frac{1}{ρ c_p}\frac{∂F_{net}}{∂z}\]

with F_net positive downward, so a downward-decreasing net flux (energy deposited in the layer) gives positive heating. ρ may be a scalar or a per-layer vector.

Aeolus.RadiationCore.ice_mass_extinction — Method
ice_mass_extinction(r_eff) -> m² g⁻¹

Shortwave mass extinction coefficient of ice cloud with effective radius r_eff (μm), k = 1/r_eff m² g⁻¹ (the form of Fu 1996 with an effective radius). 30 μm gives 0.033 m² g⁻¹. Shared like liquid_mass_extinction.

Aeolus.RadiationCore.liquid_mass_extinction — Method
liquid_mass_extinction(r_eff) -> m² g⁻¹

Shortwave mass extinction coefficient of liquid cloud with effective radius r_eff (μm), in the geometric-optics limit (extinction efficiency 2):

\[k = \frac{3}{2\,ρ_w\,r_{eff}} = \frac{1.5}{r_{eff}[\mathrm{μm}]}\ \mathrm{m^2\,g^{-1}},\]

so a layer of liquid water path LWP (g m⁻²) has τ = k·LWP (Stephens 1978; Hu & Stamnes 1993 in form). 10 μm gives 0.15 m² g⁻¹. It is the one definition used by TwoStream.MieCloudOptics and by SolarGeometry.cloud_optical_depth_column, so the cloud a column radiation scheme sees and the cloud that casts a 3-D shadow have the same optical depth.

Aeolus.RadiationCore.longwave_bands — Method
longwave_bands(T = Float64; ngpt_per_band = 2)

Default longwave SpectralGrid on the 16 RRTMG LW bands. solar_src is all zeros (there is no solar source in the thermal infrared); the source for a longwave problem is the Planck function, available via planck_band.

Aeolus.RadiationCore.material_albedo — Function
material_albedo(material, args...)

Shortwave reflectance of a named surface material.

Declared here, with no method, so that the modules which know about materials can each add their own without importing one another — the same pattern used for surface_albedo, surface_emissivity, compute_optics! and solve_rt! below.

Implemented by:

  • SurfaceOptics.material_albedo(name::Symbol, spec) → SpectralAlbedo, the spectral authority: per-band direct and diffuse reflectance derived from a reflectance curve.
  • Radiosity.material_albedo(m::UrbanMaterials, class) → scalar, the grey per-facet-class value the radiosity solve needs. Those greys are themselves derived from the spectral curves above, so the two cannot drift apart.
Aeolus.RadiationCore.material_emissivity — Function
material_emissivity(material, args...)

Longwave emissivity of a named surface material. See material_albedo for why this generic is declared here.

Aeolus.RadiationCore.net_flux! — Method

Fill flux_net = flux_dn - flux_up.

Aeolus.RadiationCore.planck_band — Method
planck_band(T_K, ν_lo, ν_hi; nquad = 8) -> W m⁻² sr⁻¹

Planck radiance integrated over a wavenumber band, ν in cm⁻¹:

\[B_Δν(T) = \int_{ν_{lo}}^{ν_{hi}} \frac{2hc^2ν^3}{e^{hcν/k_BT} - 1}\,dν\]

Evaluated by nquad-point Gauss-Legendre quadrature, which is accurate to better than 1e-6 relative for atmospheric bands and temperatures. Units come out in W m⁻² sr⁻¹ (per band, not per wavenumber).

Aeolus.RadiationCore.planck_integrated — Method
planck_integrated(T_K) -> W m⁻²

σT⁴ — the Stefan-Boltzmann integral of the Planck function over all wavenumbers and the hemisphere. Used to check that a band decomposition is complete: π·Σ_b planck_band(T, νlo_b, νhi_b) should approach this.

Aeolus.RadiationCore.scale_optics! — Method

Multiply all optical depths by a (ssa and g unchanged).

Aeolus.RadiationCore.shortwave_bands — Method
shortwave_bands(T = Float64; ngpt_per_band = 2)

Default shortwave SpectralGrid on the 14 RRTMG SW bands, with ngpt_per_band equal-weight g-points per band (so ngpt = 14·ngpt_per_band). TOA solar irradiance is distributed across bands following the RRTMG source function and renormalised so the total is exactly SOLAR_CONSTANT.

Equal g-point weights are the correct default for a reduced grid: they make the quadrature a plain band average, which is what a gas-optics implementation should reduce to when it has not been given a real k-distribution. Phase 32 supplies proper non-uniform weights.

Aeolus.RadiationCore.stitch_columns — Method
stitch_columns(lower, upper) -> AtmosphericColumn

Put the column lower, which spans the heights 0 … z_L (z_L = Σ lower.dz), under the part of upper that lies above z_L, with both columns measured from the same ground. The typical use is an LES domain a few hundred metres deep under a standard atmosphere (GasOptics.us_standard_column) up to the stratosphere, so that the downwelling longwave and the shortwave at the LES top see the whole atmosphere.

  • The layer of upper that straddles z_L is cut at z_L; its part above becomes the first upper layer (dropped if thinner than 1 mm).
  • The pressure is continuous: every upper pressure (levels, layers) and density is scaled by p_L / p_upper(z_L), where p_L is the top pressure of lower and p_upper(z_L) the upper column's own pressure there (log-linear in the straddling layer). This keeps the upper column's hydrostatic shape, and its layer masses Δp/g, up to that factor.
  • The temperature of the joining level is lower's top-level temperature; the upper levels and layers keep their own.
  • Gases present in either column are carried over; a gas missing from one column has zero mixing ratio there. Condensate and effective radii are taken from each column. The surface temperature is lower's.
Aeolus.RadiationCore.total_optical_depth — Method
total_optical_depth(o, idx...) -> Vector

Band-integrated column optical depth per band at the given horizontal index (omit idx for a column-shaped OpticalProperties). Uses the g-point weights, so this is the correct spectral integral rather than a naive mean.
