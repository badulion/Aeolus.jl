Adaptive time stepping and IMEX integration (Phases 23, 25)

Explicit diffusion imposes a $\Delta t \sim \Delta z^2 / \nu$ limit that becomes crippling in the stretched near-surface layers. Treating diffusion implicitly while keeping advection explicit removes that limit without paying for a fully implicit solve.

Aeolus.TimeIntegration.ARK2_EXPLICIT_WEIGHTS — Constant

Explicit weights (c₂ stage, δ, 1-δ) of ARS(2,2,2).

Aeolus.TimeIntegration.ARK2_IMPLICIT_WEIGHTS — Constant

Implicit weights (γ, 1-γ, γ) of ARS(2,2,2).

Aeolus.TimeIntegration.ROS2_STAGE_COEFFS — Constant

Stage coupling (a₂₁, c₂₁) of ROS2.

Aeolus.TimeIntegration.ROS2_WEIGHTS — Constant

Update weights (b₁, b₂) of ROS2.

Aeolus.TimeIntegration.ARK2 — Type
ARK2([T = Float64])

2nd-order, 2-stage additive Runge–Kutta (ARS(2,2,2), Ascher–Ruuth–Spiteri

  1. with
U₁    = uⁿ + γΔt E(uⁿ) + γΔt I(U₁)
uⁿ⁺¹  = uⁿ + Δt[δ E(uⁿ) + (1-δ) E(U₁)] + Δt[(1-γ) I(U₁) + γ I(uⁿ⁺¹)]

with γ = 1 - 1/√2, δ = 1 - 1/(2γ). The implicit tableau is L-stable (R(∞) = 0), so the stiff diffusion is damped rather than oscillating, and both halves are 2nd-order accurate. Two implicit solves and two pressure projections per step.

Aeolus.TimeIntegration.CFLConstraints — Type
CFLConstraints(; C_advective = 0.5, C_diffusive = 0.25, C_buoyancy = 0.5,
                 C_coriolis = 0.5, dt_min = 1e-8, dt_max = Inf,
                 growth_max = 1.1)

Safety factors and bounds for adaptive time stepping. Each C_* is the fraction of the corresponding linear stability limit that a step is allowed to use:

FieldLimit enforced
C_advective`dt (
C_diffusivedt (ν+νₜ) (Δx⁻²+Δy⁻²+Δz⁻²) ≤ C_diffusive (2νₜ, stress form)
C_buoyancyN dt ≤ C_buoyancy (Brunt–Väisälä / gravity-wave limit)
C_coriolis`

dt_min / dt_max clamp the result; growth_max bounds the ratio between consecutive steps so dt ramps up smoothly instead of jumping (a jump is the classic way to trip a leapfrog-free explicit scheme even though every instantaneous CFL number looks fine).

The explicit diffusive stability bound of the 7-point Laplacian with forward Euler is dt ν (Δx⁻²+Δy⁻²+Δz⁻²) ≤ 1/2, so the default C_diffusive = 0.25 is a factor-2 safety margin. Likewise C_advective = 0.5 is half the dt Σ|uᵢ|/Δxᵢ ≤ 1 bound of a 2nd-order centered / RK3 combination.

See cfl_diagnostics, adaptive_dt, step_adaptive!.

Aeolus.TimeIntegration.DiffusionWorkspace — Type
DiffusionWorkspace(field)

Preallocated scratch for solve_implicit_diffusion!: four arrays the size of field's storage (search direction, residual, operator image, preconditioned residual). Reuse one per (location, mesh) pair to keep the solve allocation-free. The diagonal is recomputed on the fly rather than stored (a handful of flops per cell, far cheaper than the matvec, and one array less).

Aeolus.TimeIntegration.IMEXScheme — Type
IMEXScheme

Additive / semi-implicit time-integration schemes. Concrete types: ARK2 (additive Runge–Kutta, ARS(2,2,2)) and Rosenbrock2 (2-stage Rosenbrock-W). Drive with step_imex!.

Aeolus.TimeIntegration.IMEXWorkspace — Type
IMEXWorkspace(sim)

Scratch state for step_imex!: the step-start state, one tendency/stage set, a lazily allocated second stage set (Rosenbrock only), one DiffusionWorkspace per staggered location (θ and qv share the cell-centered one), plus the frozen effective-viscosity arrays when SGS is on.

Memory is roughly 26 field-sized arrays for ARK2 and 31 for Rosenbrock2 — comparable to what BoussinesqSimulation itself holds. It also records the last step's solver statistics in total_iterations / max_residual.

Aeolus.TimeIntegration.NumericalFailure — Type
NumericalFailure(msg) <: Exception

The exception a dynamical core, a solver or a physics step throws when it fails numerically — an iterative solver that diverges or does not converge, a state that has left its physical range — as opposed to a programming error. Step-rejecting drivers (NestedRun) roll back and retry at a smaller step on it (is_numerical_failure); any other exception is rethrown.

Aeolus.TimeIntegration.Rosenbrock2 — Type
Rosenbrock2([T = Float64])

2-stage, 2nd-order Rosenbrock-W method (ROS2, Verwer et al. 1999):

(I - γΔt J) k₁ = Δt F(uⁿ)
(I - γΔt J) k₂ = Δt F(uⁿ + k₁) - 2k₁
uⁿ⁺¹           = uⁿ + 3/2 k₁ + 1/2 k₂

with γ = 1 + 1/√2. It is a W-method: only the diffusion part of the Jacobian is used (J ≈ ∇·(ν_eff∇)), which costs nothing extra to form and does not degrade the order — advection and buoyancy simply behave explicitly. Same cost as ARK2: two solves, two projections.

Aeolus.TimeIntegration.StateSnapshot — Type
StateSnapshot(sim)

Preallocated copy of the prognostic state (u, v, w, p, θ, qv plus the clock) used by step_adaptive! to roll a failed step back. The buffers are allocated once; save_state! and restore_state! only copy. Halos are copied too, so a restore is bit-identical to the pre-step state.

Aeolus.TimeIntegration.SubsteppingSchedule — Type
SubsteppingSchedule(; default = 1, kwargs...)
SubsteppingSchedule(:microphysics => 4, :chemistry => 2)

How many substeps each fast process takes inside one dynamics step. A process registered with n substeps is called n times with dt/n, which is how stiff-but-cheap parameterizations (Kessler microphysics, chemical kinetics, droplet sedimentation) are kept stable without shrinking the dynamical dt for the whole model.

sched = SubsteppingSchedule(microphysics = 4, chemistry = 2)
substeps_for(sched, :microphysics)   # 4
substeps_for(sched, :radiation)      # 1  (the default)
Aeolus.TimeIntegration._active — Method

Prognostic fields advanced by the IMEX drivers (qv only when moist).

Aeolus.TimeIntegration._axpy_interior! — Method

In-place y[interior] += a · x[interior].

Aeolus.TimeIntegration._diffusion! — Method
_diffusion!(out, f, ν, mesh)

Write ∇·(ν ∇f) into out's interior. ν is a scalar or a per-cell array (see solve_implicit_diffusion!); halos of f must already be filled. This is exactly the operator the implicit solve inverts, so the IMEX split is consistent by construction.

Aeolus.TimeIntegration.adaptive_dt — Method
adaptive_dt(sim, constraints; dt_prev = nothing, diagnostics = nothing,
            scheme = nothing, sgs = nothing, sgs_stress = :laplacian)

The time step to take next: the smallest per-process limit from cfl_diagnostics — or, when scheme is an IMEXScheme, the smallest limit of the processes that scheme treats explicitly (advection, buoyancy, Coriolis, scaled by explicit_cfl_factor; the dt_explicit of imex_stability_limit), because the diffusive limits do not bind an implicit diffusion solve — then

  1. limited to growth_max · dt_prev when dt_prev is given, and
  2. clamped to [dt_min, dt_max].

A non-finite limit (which only happens if the state already contains NaN/Inf) collapses to dt_min, so step_adaptive!'s retry logic sees a usable number rather than propagating the NaN. Pass diagnostics to reuse a cfl_diagnostics result instead of recomputing it; sgs is the closure the step will run and sgs_stress the form of its momentum divergence (see cfl_diagnostics).

Aeolus.TimeIntegration.cfl_diagnostics — Method
cfl_diagnostics(sim, constraints = CFLConstraints(); sgs = nothing,
                update_νt = true, sgs_active = <closure present>,
                sgs_stress = :laplacian)

Report the time-step limit imposed by each process separately. Returns a NamedTuple:

KeyMeaning
dt_advadvective limit, per-cell `Σ
dt_difftotal (molecular + SGS) momentum-diffusion limit
dt_buoyC_buoyancy / N from the resolved mean θ profile
dt_cor`C_coriolis /
dt_sgsSGS-only limit C_diffusive Δ²_harm / max(νt_cfl, κt_max)
dt_limitingmin of the five
limiter:advective, :diffusive, :buoyancy, :coriolis or :sgs
advective_rate`max_cell Σ
NBrunt–Väisälä frequency (0 when buoyancy is off)
νt_maxmaximum SGS eddy viscosity
κt_maxmaximum SGS eddy diffusivity (θ)
νt_cflSGS viscosity of the momentum limits (see sgs_stress)
ν_totalν + νt_cfl

The SGS closure is the one the next step will run: the sgs keyword (an AbstractSGSClosure or a function f(νt, u, v, w)), else the built-in Smagorinsky when C_s ≠ 0. With update_νt = true (the default) its coefficients are recomputed from the current state into sim.νt / sim.κt with the pure compute_sgs! — no closure memory advances, so the estimate can be made any number of times per step; pass false to reuse what is in sim.νt / sim.κt. sgs_active (default: a closure is present) says whether an eddy viscosity acts on the step at all.

sgs_stress is the form of the SGS momentum divergence the step runs (the cores' keyword). For :laplacian (the default), νt_cfl = νt_max. For :symmetric, the stress form's factor 2 on the normal stresses can double the operator's spectral radius, so νt_cfl = stress_form_cfl_viscosity(νh_max, νv_max, mesh), which equals 2 νt_max when νh = νv.

The SGS limit uses the larger of the momentum viscosity νt_cfl and the eddy diffusivity, each as stored: for a Prandtl-number closure κt = νt/Prₜ, for a closure with its own κ (Era VI) whatever it computed.

Ties are broken in the table order above, so a pure-molecular run where dt_diff == dt_sgs reports :diffusive.

Aeolus.TimeIntegration.explicit_cfl_factor — Method
explicit_cfl_factor(scheme)

Fraction of the nominal advective CFL limit the explicit half of scheme can use. Both shipped schemes have a 2-stage explicit tableau whose stability region along the imaginary axis is comparable to forward-Euler-with-safety, so this is 1 and the limit is whatever CFLConstraints.C_advective says.

Aeolus.TimeIntegration.imex_stability_limit — Method
imex_stability_limit(sim, scheme; constraints = CFLConstraints(), sgs = nothing,
                     sgs_stress = :laplacian)
-> (; dt_explicit, dt_diffusive, dt_fully_explicit, speedup, limiter,
      explicit_limiter, diagnostics)

Quantify what treating diffusion implicitly buys.

  • dt_explicit — the limit from the explicit half alone (advection, buoyancy, Coriolis), scaled by explicit_cfl_factor. This is the step step_imex! can take.
  • dt_diffusive — the Δ²/ν_eff limit that would apply if diffusion were explicit (min(dt_diff, dt_sgs)).
  • dt_fully_explicit — min of the two, i.e. what step! is bound by.
  • speedup — dt_explicit / dt_diffusive, the achievable factor when diffusion is the binding constraint (values ≤ 1 mean diffusion was not limiting and IMEX buys nothing but robustness).

limiter names the process that binds the IMEX step, explicit_limiter the one that binds a fully explicit step, and diagnostics is the full cfl_diagnostics result (with the SGS closure sgs and the momentum form sgs_stress, as there).

Aeolus.TimeIntegration.imex_workspace — Method
imex_workspace(sim) -> IMEXWorkspace

The IMEXWorkspace associated with sim, allocated on first use and cached weakly so it is freed with sim. Pass it explicitly to step_imex! if you want to control the lifetime (or read the solver statistics it records).

Aeolus.TimeIntegration.is_numerical_failure — Method
is_numerical_failure(err, sim) -> Bool

Whether the exception err, thrown by a step of sim, is a numerical failure that a smaller step may cure, rather than a bug to be reported:

  • a NumericalFailure (a solver that diverged);
  • a DomainError (sqrt/log of a negative value), an InexactError (a non-finite value converted to an integer, e.g. a step count ceil(Int, R/Δt) from an infinite rate) or an OverflowError;
  • any exception thrown while the prognostic state of sim has become non-finite (the throw is a consequence of the blow-up).

A MethodError, BoundsError, ArgumentError, DimensionMismatch, … thrown from a finite state is a programming or set-up error: retrying it at half the step only hides it (#327, M6). An InterruptException is never a numerical failure.

Aeolus.TimeIntegration.solve_implicit_diffusion! — Method
solve_implicit_diffusion!(field, rhs, ν_eff, dt, mesh, bcs;
                          tol = 1e-10, maxit = 200,
                          workspace = DiffusionWorkspace(field),
                          precondition = :jacobi, warn = true)
-> (; iterations, residual, relative_residual, converged, tol)

Solve (I − dt ∇·(ν_eff ∇)) φ = rhs for φ (written into field), matrix-free, with Jacobi-preconditioned conjugate gradients.

  • ν_eff is either a scalar or an Array{T,3} — per-cell eddy viscosity, given at full storage size (halos included) or at interior size. Arrays use the face average ν_{i+1/2} = ½(νᵢ + ν_{i+1}), which keeps the operator symmetric, hence CG-legal (I − dt L with L symmetric negative-semidefinite is SPD for dt ≥ 0). A pair (ν_h, ν_v) of such coefficients is a per-direction coefficient: ν_h on the x and y faces, ν_v on the z faces (P55-b, #175).
  • Boundary conditions are applied by calling fill_halos!(·, bcs) on the search direction inside every matrix-vector product, so exactly the BC types fill_halos! supports are supported here: Periodic, NoFlux, ImpermeableWall and NoSlipWall. ValueBC/FluxBC make the operator affine and are rejected with an explanatory error. For w on an impermeable wall the pinned wall-face row is eliminated from the system.
  • A moving NoSlipWall (u_wall or v_wall ≠ 0) also makes the operator affine, ∇·(ν∇φ) = L₀φ + g; this one is handled: the CG iterates with the stationary wall (homogeneous_bcs) and the wall term dt·g is added to the right-hand side, so φ is the solution with the wall moving. Pass homogeneous_bcs(bcs) yourself when φ is an increment (a Rosenbrock stage), whose wall value is zero.
  • An OpenBoundary (N-open-b) is affine in the same way and handled the same way: the CG iterates with zero boundary values and the Dirichlet lift (the boundary data in the halos and in the pinned west/south face rows) is carried in the right-hand side; after the solve the field's halos and boundary faces are refilled with the data. key names the field whose boundary data apply (default field.data; a Rosenbrock increment passes the prognostic field's array).
  • field doubles as the initial guess, and rhs === field is explicitly allowed (build the right-hand side in place, then solve over it — that is what step_imex! does).
  • ν_eff == 0 or dt == 0 short-circuits to a copy.

Convergence is ‖r‖₂ ≤ tol·‖b‖₂ over the interior. The returned NamedTuple reports the iteration count and the final (absolute and relative) residual; converged = false plus a warning if maxit is hit.

Preconditioning is diagonal (Jacobi), which is enough to make the iteration count nearly independent of dt·ν/Δ² in practice for the grid-aligned anisotropies LES actually has. Geometric-multigrid preconditioning — the right answer for very stiff dt ν / Δz² on tall stretched grids — is the Phase-29 follow-up (src/Multigrid.jl); this solver is deliberately written so that only z ← M⁻¹r needs replacing.

Aeolus.TimeIntegration.step_adaptive! — Method
step_adaptive!(sim, constraints; dt = nothing, dt_prev = nothing,
               body_force! = nothing, post_predictor! = nothing,
               fast_processes = nothing, schedule = SubsteppingSchedule(),
               max_retries = 3, stepper = step!, scheme = nothing,
               snapshot = state_snapshot(sim),
               divergence_tol = 1e-6, max_velocity = Inf, sgs = nothing)
-> (sim, dt_used, n_retries)

Production adaptive driver. One call:

  1. picks dt from adaptive_dt (or uses the dt you pass, which is how you deliberately overshoot the stability limit); with scheme = ARK2() the pick uses only the explicit processes' limit, since the diffusion is implicit;
  2. saves the prognostic state into a preallocated StateSnapshot;
  3. takes the step with stepper(sim, dt; body_force!, post_predictor!) — pass scheme = ARK2() to step with step_imex! instead;
  4. validates the result. A step fails if it throws, if any prognostic value is non-finite, if max_divergence(sim) > divergence_tol (the projection should leave it at roundoff, so a finite but large divergence means the solve diverged), or if max|u| > max_velocity (an optional physical ceiling — the cheapest reliable runaway detector). On failure the state is restored, dt is halved (never below constraints.dt_min) and the step is retried, up to max_retries times. If every retry fails the pre-step state is restored and an error is thrown.
  5. runs each fast process substeps_for(schedule, name) times with dt/n.

SGS closure. sgs is the closure the step runs (an AbstractSGSClosure or a function f(νt, u, v, w); default: the built-in Smagorinsky when C_s ≠ 0). It sets the diffusive limit of the dt pick, it is passed to the default stepper (step! / step_imex!), and its memory is saved with sgs_state next to the prognostic snapshot and restored with restore_sgs_state! whenever a step is rejected — the commit (advance_sgs!) a rejected step made is undone, so after a retry the closure's memory is that of a run that took the short step directly. A custom stepper is called without sgs and must pass the same closure to the step it takes itself. sgs_stress (:laplacian | :symmetric) is passed to the default stepper with the closure, and to adaptive_dt for the stress form's diffusive limit.

fast_processes accepts a NamedTuple, Dict, vector/tuple of :name => callback pairs, or a bare callback (registered as :default). Each callback is invoked as callback(sim, dt_sub).

Every rejected step is a structured event (subsystem = :timestepping, keys reason, from, to, retry; a throw also carries exception) at Debug: a retry the driver recovers from is not a problem, so a run log records it while the console stays quiet (install a logger at Debug to see it there). A step that fails after max_retries throws; a fast process that leaves non-finite values is a warning. See the Logging page (#333, #347).

c = CFLConstraints(dt_max = 10.0)
sched = SubsteppingSchedule(microphysics = 4)
dt = nothing
for n in 1:100
    _, dt, nretry = step_adaptive!(sim, c; dt_prev = dt, schedule = sched,
        fast_processes = (microphysics = (s, Δt) -> apply_kessler_step!(s, Δt),))
end
Aeolus.TimeIntegration.step_imex! — Method
step_imex!(sim, dt, scheme::IMEXScheme; body_force! = nothing,
           post_predictor! = nothing, workspace = imex_workspace(sim),
           tol = 1e-10, maxit = 200,
           momentum_advection = momentum_advect!, sgs = nothing,
           sgs_stress = :laplacian)

Advance sim by dt with a semi-implicit IMEX scheme (ARK2 or Rosenbrock2):

  • explicit: momentum and scalar advection, buoyancy, Coriolis, prescribed surface flux, Rayleigh sponge, and the user body_force!;
  • implicit: diffusion of u, v, w, θ (and qv when moist) with the frozen effective viscosity ν + νₜ (ν + κₜ for scalars; κₜ = νₜ/Prₜ for the Smagorinsky closures; qv takes the closure's sgs_tracer_diffusivity!, which for AMD is its own diffusivity from the qv gradient), solved by solve_implicit_diffusion!;
  • pressure projection at the end of every stage, so each stage value — and therefore the returned state — is discretely divergence-free.

The payoff is that dt is no longer restricted by Δz²/ν_eff: see imex_stability_limit for the two limits side by side. Both callbacks follow step!'s convention — body_force!(sim, Δt_stage) contributes to the explicit tendency, post_predictor!(sim, Δt_stage) runs after the implicit solve and before the projection, so a velocity correction it applies is folded into a divergence-free result.

The two operator keywords are step!'s as well, so a driver can pass the same keywords to either: momentum_advection(tu, tv, tw, u, v, w) is the (explicit) momentum-advection operator, and sgs (an AbstractSGSClosure, or a function f(νt, u, v, w); the legacy name eddy_viscosity! is still accepted), when given, replaces the Smagorinsky closure in the frozen ν_eff = ν + νt (momentum) and ν + κt (scalars) — it is applied even with C_s = 0, as in step!. Its coefficients are computed once, at uⁿ, and its memory is committed (advance_sgs!) once, after the last stage.

Notes and limitations:

  • The implicit operator is ∇·(ν_eff ∇·) with ν_eff face-averaged from cell centers. With C_s = 0 this is exactly the molecular term ν∇² that step! applies explicitly, so the two drivers differ only by truncation error. With SGS on and sgs_stress = :laplacian (the default), the implicit operator is a co-located approximation of the Laplacian eddy-viscosity divergence (the edge interpolation that add_eddy_viscosity_u! uses is not reproduced exactly); it is 2nd-order consistent and SPD, which is what the implicit solve needs, and the coefficient is lagged by one step either way.
  • sgs_stress = :symmetric (P55-b) splits the stress-form divergence ∂ⱼ[νᵢⱼ(∂ⱼuᵢ + ∂ᵢuⱼ)] of step! into its diagonal part ∂ⱼ(νᵢⱼ∂ⱼuᵢ), implicit, with per-direction coefficients (ν + νh on the x/y faces of the 11, 22, 12 fluxes, ν + νv on the 33, 13, 23 ones) and exactly the interpolation of the explicit kernel — the operator is the explicit part = :diagonal of add_sgs_stress_divergence! and stays symmetric, so I − γΔt L is SPD — and the transposed cross terms ∂ⱼ(νᵢⱼ∂ᵢuⱼ), explicit, evaluated at each stage value with the same frozen coefficients. For constant ν the cross terms are ν∂ᵢ(∇·u), zero on the projected stage values, so the split is exact there; they matter only where ν varies, where they are not stiff (no second derivative of uᵢ along xⱼ of its own component).
  • ν_eff is frozen at uⁿ for the whole step.
  • Returns sim. The step's solver statistics are in workspace.total_iterations and workspace.max_residual.
Aeolus.TimeIntegration.stress_form_cfl_viscosity — Method
stress_form_cfl_viscosity(νh_max, νv_max, mesh) -> ν_cfl

The eddy viscosity that, put into the Laplacian diffusive limit dt ν (Δx⁻²+Δy⁻²+Δz⁻²) ≤ 2 of forward Euler, bounds the explicit stress-form SGS momentum operator −∂ⱼτᵢⱼ, τᵢⱼ = −2νᵢⱼSᵢⱼ (add_sgs_stress_divergence!), for any velocity field and any 0 ≤ νh ≤ νh_max, 0 ≤ νv ≤ νv_max:

ν_cfl = 2 max(νh_max (Δx⁻²+Δy⁻²) + νv_max Δz⁻²,  νv_max (Δx⁻²+Δy⁻²+Δz⁻²))
          / (Δx⁻²+Δy⁻²+Δz⁻²)

so ν_cfl = 2 νt when νh = νv. Derivation: the operator is symmetric negative semi-definite, −⟨u, L u⟩ = Σ 2νᵢⱼSᵢⱼSᵢⱼ ΔV, so its spectral radius is the largest Rayleigh quotient. Each diagonal strain is one difference, (u_{i+1}−u_i)²/Δx² ≤ 2(u_{i+1}²+u_i²)/Δx², and each off-diagonal pair is bounded by (a+b)² ≤ 2a²+2b²; every face value enters two differences per direction, so the u and v rows contribute at most 8(νh_max Δx⁻² + νh_max Δy⁻² + νv_max Δz⁻²) and the w row (which sees only νv) 8 νv_max (Δx⁻²+Δy⁻²+Δz⁻²). That is twice the 7-point-Laplacian radius 4ν(Δx⁻²+Δy⁻²+Δz⁻²). The factor 2 comes from the normal stresses τᵢᵢ = −2ν∂uᵢ/∂xᵢ. The bound is sharp: with constant ν it is reached by the irrotational grid-scale mode u = ∇φ, φ a 3-D checkerboard, where the operator is ν(∇² + ∇∇·) and both terms give −4ν(Δx⁻²+Δy⁻²+Δz⁻²).

On projected fields the radius of the projected operator P L P is no larger than the Laplacian bound, because Σ 2S:S = Σ|∇u|² for solenoidal periodic u. cfl_diagnostics still uses this unprojected bound for sgs_stress = :symmetric: it holds for every velocity field, not just for one an exact orthogonal projection has made divergence-free (see the theory page, "Explicit stability of the stress form").
