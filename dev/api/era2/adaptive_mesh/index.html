Block-structured AMR (Phase 31)

The AMR hierarchy delegates its prolongation, restriction and refluxing to the parent ↔ child operators of Aeolus.Nesting.

Aeolus.AdaptiveMesh.AMRHierarchy — Type
AMRHierarchy

The level structure: levels[ℓ] is the vector of RefinementBlocks at level ℓ (levels[1] always holds the single root block covering the base grid). Blocks at one level never overlap; levels deeper than 1 are built by regrid!, which enforces proper nesting with a buffer.

Fields of interest: base, refinement ((rx,ry,rz)), max_level, vars (advected scalars), velocity (a prescribed (x,y,z,t) -> (u,v,w)), advance! (per-block update), order (prolongation order), buffer, t, nstep.

Aeolus.AdaptiveMesh.RefinementBlock — Type
RefinementBlock

A rectangular patch of refined mesh.

  • level — 1 for the base (root) block, 2 for the first refined level, …
  • bounds — index range (ix, iy, iz) in this level's global index space (base.N .* r.^(level-1) cells). Always aligned to the parent level's cell boundaries.
  • mesh — the block's own RegularGrid (with halos).
  • state — Dict{Symbol,Field}: the advected scalars, the velocity :u, :v, :w, and the time-accumulated flux registers :Fx_θ, :Fy_θ, :Fz_θ used for refluxing.
  • parent / children — the level links.
  • nest — the NestedGrid relating this block to its parent (prolongation / restriction / refluxing operators).
Aeolus.AdaptiveMesh._amr_advect! — Method
_amr_advect!(hierarchy, block, dt, t)

Default per-block update: flux-form first-order-upwind advection of every scalar in hierarchy.vars by the block's velocity. The face fluxes are accumulated (×dt) into the block's flux registers, which is what makes Berger-Colella refluxing — and therefore exact composite conservation — possible. Replace via the advance! keyword of amr_hierarchy.

Aeolus.AdaptiveMesh._full_span — Method

true when b spans the whole domain along dimension d at its own level — then there is no coarse-fine interface in d, only a periodic seam.

Aeolus.AdaptiveMesh._reflux_block! — Method

Berger-Colella refluxing of one block into its parent: the coarse cells just outside the block absorb coarse flux − Σ fine fluxes on every coarse-fine interface plane. Directions in which the block spans the whole (periodic) domain carry no interface and are skipped.

Aeolus.AdaptiveMesh._restrict_legal! — Method

Zero the mask within buffer cells of pb's sides that are not domain edges.

Aeolus.AdaptiveMesh._try_split — Method
_try_split(mask, box, min_size) -> ((box1, box2) | nothing)

Berger-Rigoutsos split selection. Longest dimension first: prefer a hole in the signature (a slice with no flagged cells), otherwise the strongest inflection of the signature's second difference (a sign change in Σᵢ₊₁ - 2Σᵢ + Σᵢ₋₁). Falls back to a midpoint bisection so progress — and therefore termination — is guaranteed.

Aeolus.AdaptiveMesh.amr_error — Method
amr_error(hierarchy, exact; var=:θ) -> Float64

Volume-weighted composite L1 error of var against exact(x, y, z), evaluated on each block's uncovered cells at that level's resolution.

Aeolus.AdaptiveMesh.amr_hierarchy — Method
amr_hierarchy(base_mesh; refinement=(2,2,2), max_level=2, vars=[:θ],
              velocity=nothing, advance! = _amr_advect!, order=3,
              bcs=FieldBoundaryConditions(:periodic), buffer=2)

Build a one-level hierarchy whose root block covers base_mesh. Call regrid! (or step_amr! with a criterion) to create the refined levels.

Aeolus.AdaptiveMesh.amr_total_mass — Method
amr_total_mass(hierarchy; var=:θ) -> Float64

Composite volume integral of var: every cell of every block that is not covered by a finer block, weighted by that level's cell volume. This is the quantity step_amr! conserves exactly.

Aeolus.AdaptiveMesh.box_efficiency — Method
box_efficiency(mask, boxes) -> Float64

Achieved clustering efficiency: flagged cells inside boxes divided by the total cell count of boxes.

Aeolus.AdaptiveMesh.check_proper_nesting — Method
check_proper_nesting(hierarchy; buffer=hierarchy.buffer) -> Bool

true when every level-n+1 block, coarsened to level-n index space, lies inside a level-n block with at least buffer level-n cells of margin on every side — except on sides where the containing level-n block itself abuts the domain boundary, where the margin is unnecessary (and impossible).

Aeolus.AdaptiveMesh.cluster_flagged_cells — Method
cluster_flagged_cells(mask; min_efficiency=0.7, max_blocks=64, min_size=1)
    -> Vector{NTuple{3,UnitRange{Int}}}

Berger-Rigoutsos signature-based clustering: turn a scattered Bool flag mask into a small set of efficient, non-overlapping rectangular boxes.

A box is accepted when its efficiency (flagged cells / box cells) reaches min_efficiency, when it can no longer be split, or when the max_blocks budget is exhausted; otherwise it is split at a signature hole or inflection (see _try_split) and each half is re-tightened to its bounding box. Report the achieved efficiency with box_efficiency.

Aeolus.AdaptiveMesh.combine_criteria — Method
combine_criteria(masks...; mode=:union) -> BitArray{3}

Combine refinement masks. mode: :union (flag if any), :intersection (flag only if all), :majority (flag if at least half).

Aeolus.AdaptiveMesh.refinement_criterion_gradient — Method
refinement_criterion_gradient(x; field=:θ, threshold=0.1, ε=0.01) -> BitArray{3}

Löhner-style normalized second-derivative indicator on field (x may be a BoussinesqSimulation, a RefinementBlock or a Field). For each direction

e = |fᵢ₊₁ - 2fᵢ + fᵢ₋₁| / (|fᵢ₊₁-fᵢ| + |fᵢ-fᵢ₋₁| + ε(|fᵢ₊₁| + 2|fᵢ| + |fᵢ₋₁|))

and the mask flags cells where max(eₓ, e_y, e_z) > threshold. The ε term is what keeps smooth and flat regions unflagged — without it the indicator saturates on round-off. The indicator is dimensionless, so threshold is scale-free. Domain-boundary cells contribute 0 in the affected direction (no reliance on halo contents).

Aeolus.AdaptiveMesh.refinement_criterion_richardson — Method
refinement_criterion_richardson(x; field=:θ, threshold=0.05, p=2) -> BitArray{3}

Richardson-extrapolation error estimate — the most defensible criterion because it estimates the discretization error itself rather than a proxy for it. The field is restricted to a 2× coarser mesh (in every direction whose extent is even), prolonged back trilinearly, and the difference divided by 2^p - 1 (with p the scheme's formal order) gives the local error estimate. Normalized by the field's range; cells exceeding threshold are flagged.

Aeolus.AdaptiveMesh.refinement_criterion_vorticity — Method
refinement_criterion_vorticity(x; threshold=0.2, relative=true) -> BitArray{3}

Flag cells by vorticity magnitude |ω| — the natural LES criterion, since |ω| marks the shear layers and coherent structures that carry the SGS burden. u, v, w are averaged to cell centres and differentiated with centred (one-sided at the domain edge) differences. With relative=true (default) threshold is a fraction of max|ω|; otherwise it is absolute.

Aeolus.AdaptiveMesh.regrid! — Method
regrid!(hierarchy, criteria; buffer=hierarchy.buffer, min_efficiency=0.7,
        max_blocks=64, min_size=1)

Rebuild the refined levels. criteria is either a function block -> Bool mask (evaluated on every block of the level being refined) or a Bool array over the base grid.

Per level: evaluate the criterion, dilate the flags by buffer cells, clip to the legally nestable region (buffer cells inside the parent block, except at domain boundaries), cluster with cluster_flagged_cells, then transfer state — conservative prolongation where refinement is new, direct copy where an old block overlapped, and the parent already holds the restricted averages where refinement disappeared. Proper nesting is guaranteed by construction; see check_proper_nesting.

Aeolus.AdaptiveMesh.step_amr! — Method
step_amr!(hierarchy, dt; regrid_interval=10, criterion=nothing)

One coarse step of the recursive, subcycled AMR advance:

  • advance every level-ℓ block by dt, accumulating face fluxes into the flux registers;
  • take r = max(refinement) substeps of level ℓ+1 with dt/r, filling the fine halos from the coarse level by conservative prolongation;
  • restrict the fine interior onto the coarse cells and reflux the coarse-fine flux mismatch into the coarse cells just outside each fine block.

That last pair is what makes the composite integral exactly invariant: the coarse level was advanced with coarse fluxes across the interface while the fine level used the fine ones, and refluxing removes the difference.

Regrids every regrid_interval coarse steps when criterion !== nothing (pass regrid_interval=0 to disable).
