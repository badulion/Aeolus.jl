Dynamic input driver

The dynamic driver holds what changes in time: initial profiles, large-scale forcing, surface series and boundary data (CFG-g, #362). AeolusPrep.jl writes it (aeolusprep dynamic), or an Aeolus parent run ([urban] child_boundaries). Generated from its DriverSchema by InputDrivers.format_reference when the docs are built.

The dynamic driver, form "standard"

Initial state, boundary planes and large-scale and surface forcing over time. Every group is optional. Besides the variables below, the boundary planes are one variable bc_<face>_<var> per open face (west, east, south, north, top) and field with data, over (bc_<face>_<var>_i, _j, _k, time_bc): the child's buffer slab (the face plane plus the halo layers), with attributes field, side, i0, j0, k0 (the slab's first storage index) and halo_mode.

A file of this form has the global attributes aeolus_driver = "dynamic", aeolus_form = "standard" and aeolus_schema_version = 1; a file of another kind, form or version is refused (check_driver). NetCDF-4, CF-1.8 attributes; dimensions are in Julia index order (the first varies fastest; ncdump lists them in the reverse, C order); * is the variable's own coordinate.
