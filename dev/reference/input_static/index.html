Static input driver

The static driver holds what does not change during a run: terrain, land use, buildings, trees, surfaces (CFG-f, #361). AeolusPrep.jl writes it (aeolusprep static). Generated from its DriverSchema by InputDrivers.format_reference when the docs are built.

The static driver, form "resolved"

Terrain, buildings and surface classes on the run's grid, plus the footprint polygons.

A file of this form has the global attributes aeolus_driver = "static", aeolus_form = "resolved" and aeolus_schema_version = 1; a file of another kind, form or version is refused (check_driver). NetCDF-4, CF-1.8 attributes; dimensions are in Julia index order (the first varies fastest; ncdump lists them in the reverse, C order); * is the variable's own coordinate.

The static driver, form "tiles"

Surface-class counts and building morphometry per column of a coarse grid.

A file of this form has the global attributes aeolus_driver = "static", aeolus_form = "tiles" and aeolus_schema_version = 1; a file of another kind, form or version is refused (check_driver). NetCDF-4, CF-1.8 attributes; dimensions are in Julia index order (the first varies fastest; ncdump lists them in the reverse, C order); * is the variable's own coordinate.

class_countx, y, classInt32yes[0, 2147483647]fine cells of each surface class: out of refinement² per column (attribute)
