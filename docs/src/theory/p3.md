# P3 microphysics

The Predicted Particle Properties (P3) scheme of Morrison & Milbrandt
(2015) represents all ice by a single category whose bulk properties —
rime fraction, rime density, and hence the mass–dimension relation — are
prognosed rather than fixed by assigning particles to "cloud ice",
"snow", "graupel" or "hail". This page develops the pieces as they are
implemented in `Aeolus.P3Microphysics` (Phase 40); the API is in
[Era IV — microphysics](../api/era4.md).

## Gamma size distributions and their moments

Every hydrometeor population in P3 is a complete gamma distribution in
maximum dimension ``D``,

```math
N(D) = N_0\, D^{\mu}\, e^{-\lambda D},
```

with intercept ``N_0``, shape ``\mu`` and slope ``\lambda``. Its
``k``-th moment is

```math
M_k = \int_0^\infty D^k N(D)\,dD = N_0\,\frac{\Gamma(\mu+k+1)}{\lambda^{\mu+k+1}} ,
```

so the number is ``M_0``, the mass of spheres of density ``\rho`` is
``(\pi/6)\rho M_3``, and the Rayleigh reflectivity factor of liquid
spheres is ``M_6``. Given two moments ``M_i, M_j`` and a fixed ``\mu``,
the slope follows from their ratio,

```math
\lambda = \left[\frac{M_i}{M_j}\,
          \frac{\Gamma(\mu+j+1)}{\Gamma(\mu+i+1)}\right]^{1/(j-i)},
```

and ``N_0 = M_0 \lambda^{\mu+1}/\Gamma(\mu+1)``.

### Truncated moments

P3's mass–dimension relation ``m(D)`` is a *piecewise* power law, with
different prefactors and exponents on either side of the thresholds
``D_\mathrm{th}``, ``D_\mathrm{gr}``, ``D_\mathrm{cr}``. Every bulk
integral therefore splits into moments truncated to one regime:

```math
\int_{D_1}^{D_2} D^k N(D)\,dD
  = N_0\,\frac{\Gamma(a)}{\lambda^{a}}
    \left[P(a,\lambda D_2) - P(a,\lambda D_1)\right],
  \qquad a = \mu+k+1,
```

where ``P(a,x) = \gamma(a,x)/\Gamma(a)`` is the regularised lower
incomplete gamma function and ``Q = 1 - P`` its complement. When the
interval sits in the upper tail (``\lambda D_1 > a``) the difference is
formed as ``Q(a,\lambda D_1) - Q(a,\lambda D_2)`` so that a small tail
contribution does not vanish in the cancellation of two numbers near one.

### Numerical evaluation

`SpecialFunctions` does not build on every target, so the functions are
implemented in-package following Press et al. (2007, *Numerical Recipes*
3rd ed., §6.1–6.2):

* ``\ln\Gamma(x)`` by the 14-term Lanczos approximation for ``x \ge 1/2``
  and Euler's reflection ``\Gamma(x)\Gamma(1-x) = \pi/\sin \pi x`` below;
  ``\Gamma`` at positive integers is the exact factorial product.
* ``P(a,x)`` by its power series for ``x < a+1`` and ``Q(a,x)`` by its
  continued fraction, evaluated with the modified Lentz algorithm,
  otherwise. The smaller of the two is always the one computed directly.

Measured accuracy (Float64, from the test suite):

| Check | Max. error |
| :-- | :-- |
| ``\Gamma`` at ``1, \tfrac12, 5, \tfrac13, \tfrac14, -\tfrac12, \dots`` | 8.3e-16 rel. |
| ``\ln\Gamma(n)`` vs exact ``\ln (n-1)!``, ``n \le 10^4`` | 8.0e-16 rel. |
| recurrence ``\Gamma(x+1) = x\Gamma(x)``, 447 points in ``(-5, 30)`` | 3.7e-14 rel. |
| reflection ``\Gamma(x)\Gamma(1-x) = \pi/\sin\pi x`` | 1.5e-15 rel. |
| Legendre duplication (log form), ``0 < x < 20`` | 2.8e-14 abs. |
| ``P(1,x) = 1-e^{-x}``, ``Q(1,x) = e^{-x}`` | 3.7e-15 rel. |
| ``P(\tfrac12,x) = \mathrm{erf}\sqrt{x}`` (GasOptics `erf_series`) | 3.1e-14 rel. |
| ``Q(\tfrac12,x) = \mathrm{erfc}\sqrt{x}``, 256-bit reference, ``x \le 30`` | 3.6e-15 rel. |
| ``Q(n,x)`` = Poisson sum, ``n \le 50``, smaller tail | 2.8e-14 rel. |
| truncated PSD moments vs Simpson quadrature | 4.3e-13 rel. |
| sum of truncated moments vs full moment | 1.7e-16 rel. |
